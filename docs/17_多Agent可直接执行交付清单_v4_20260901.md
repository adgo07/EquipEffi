### 1.2 输入语义和字段门禁

- 所有值是出厂设计值、额定值或铭牌值，不恢复“实测值”。
- 不恢复“设备位号”和“是否在标准适用范围”。
- 效率字段按百分数本值填写：`98`表示98%；一般范围1～100；冷凝锅炉设计热效率例外为1～110。
- 功率因数范围0～1；COP、EER、SEER、APF、IPLV等比值只要求大于0。
- 数量必须为正整数；容量、功率、流量、扬程、压力、损耗、级数等正数/非负数规则必须按V4和标准证据设置。
- 不确定的同义词、单位或边界不能猜；保留原值并写入数据质量问题。
- 自动备注只写输入质量问题；能效判断问题写入判定说明和轨迹。

### 1.3 标准、PMSM和淘汰门禁

- 标准原文优先，其次是逐项复核的人可读校对册；不得用旧JSON或粗校对永磁电机表。
- PMSM仅允许`gb30253_2024_pdf_verified_v1`。表1、55 kW、12极的1～3级均为“—”，命中必须返回`不在范围`，并保留无数据查表轨迹。
- `—`表示该档没有标准数据或该档不作要求，不能填0，不能自动插值，不能向最近档外推。
- 默认淘汰口径为`高耗能落后机电设备淘汰目录第一至第四批`。
- 产业目录仅使用当前已核对的设备相关受控规则；命中不完整条件时返回`无法判定`，不能模糊相似判淘汰。

## 7. T03：设备算法验收任务卡

每次只做一个设备族。先写失败测试，再改评价器；不得只断言最终等级，必须断言中间数据和轨迹。

### 通用步骤

1. 确认公开类型、内部profile、标准`pack_id`、标准编号、表号、数据版本。
2. 从标准原文或已确认校对数据确定算法；没有证据时返回`无法判定`，不能用经验公式。
3. 设计至少六类用例：精确档、边界、允许插值、禁止外推、缺失字段、最低等级以下/未达标。
4. 如设备存在“—”，增加无数据用例，确认不是0、不是普通空值。
5. 修改对应`src/equipeffi/domain/evaluation/evaluators/`，不把规则复制到Excel或窗口。
6. 检查结果字段：`actual_metrics`、`calculated_metrics`、`limits`、`lookups`、`comparisons`、`trace`。
7. 检查淘汰优先级、结论允许值和标准来源追溯。

| 空压机 | 型式、工频/变频、压力、机组比功率查表 | 不取最近档、不外推；精确档未命中时保留查询条件和可用档位摘要 |
| 清水/石化离心泵 | 输出功率、比转速、C1～C3、基准/修正/规定点效率 | 双吸半流量，多级单级扬程；缺级数不默认1；流量/比转速未命中时保留候选查表记录 |
| 离心/轴流通风机 | 压力、圆周速度、压缩性修正、压力系数、比转速/轮毂比、结构修正 | 结构条件按AND；机号/轮毂比缺失保守处理；压力系数、次级档或机号未命中时保留候选查表记录 |
| 鼓风机 | 进口/出口绝压温度、绝热指数、多变效率、`b₂/D₂`、表号 | 2012 active；2026仅记录待实施；“—”非0 |
| 潜水电泵 | `ηSP`、`Δη`、`ηB`、`ηDB`、三级阈值和产品标准 | 不支持证据不足时的插值/外推 |
| 工业锅炉 | 容量基准D/Q、燃烧方式、燃料、热值、挥发分、冷凝条件、热效率、稳定标准`data_id` | 蒸发量和热功率至少一项；冷凝103可、非冷凝103不可；查表记录必须可回指标准包；匹配失败也保留候选条件 |
| 热处理设备 | 炉型、额定功率/温度、燃料系数α、可比单耗、稳定标准`data_id` | 能源类型与能耗字段匹配；未知燃料不默认α=1；查表记录必须可回指标准包 |
| 热泵/冷水机组 | 主指标、辅助指标、固定门槛、表号和AND/OR通道 | “—”跳过该档要求；固定门槛只约束声明的等级 |
| 热泵热水机 | 类型、加热方式、带泵、制热量档、1～5级COP | 10kW容量边界和等于阈值用例 |
| 风管/单元式空调 | 自动选定SEER/APF/IPLV/EER/AEER、查表值 | 类别与指标不匹配需无法判定 |
| 多联式空调 | 静压修正输入、主指标、EER门槛、低温COP门槛 | 正静压必须有标准修正值/系数；0合法且不强制修正 |

### 算法硬规则

- 用十进制定点数；等于阈值视为达到。
- 只有标准明确允许时才能插值；不得外推、不得取最近档、不得统一向上取整。
- 双轴插值必须记录两个轴的端点和系数。
- 标准规定必须计算的指标以计算值判定，填报值仅用于交叉检查。
- 缺少可靠物理参数时返回`无法判定`并列出缺失字段。

## 8. T04：标准数据审计任务卡

## 9. T05：淘汰目录任务卡

### 当前口径

### 命中条件
