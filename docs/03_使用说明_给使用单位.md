# 设备能效分析工具 —— 使用说明（给使用单位）

版本：v0.1.0　更新：2026-08-17

## 一、工具是什么

本工具用于分析工业企业**用能设备的能效等级**。把企业填好的《设备台账》Excel交给工具，
工具自动完成：数据检查 → 标准匹配 → 能效等级判定 → 汇总统计，并输出一份带判定结果的新Excel
（**企业填写的所有内容、铭牌照片原样保留**）。

支持设备类型（12类）：

| 类别 | 依据标准 |
|---|---|
| 变压器 | GB 20052-2024 |
| 低压电动机 | GB 18613-2020 |
| 高压电动机 | GB 30254-2024 |
| 永磁同步电机 | GB 30253-2024 |
| 空压机 | GB 19153-2019 |
| 清水离心泵 / 化工离心泵 | GB 19762-2025 |
| 通风机 | GB 19761-2020 |
| 鼓风机 | GB 28381-2012 |
| 潜水电泵 | GB 32030-2022 |
| 工业锅炉 | GB 24500-2020 |
| 热处理设备 | GB/T 36561-2018 |

## 二、文件构成

| 文件 | 说明 |
|---|---|
| 设备能效分析工具.exe | 主程序（双击运行，无需安装） |
| standards\ 文件夹 | 标准数据（**不要删**；升级标准时替换里面的文件即可） |

三个文件放同一个文件夹，发给使用单位即可。

## 三、操作步骤（三步）

### 第1步：填写设备台账
打开企业填写的《设备能效分析表》Excel，按各sheet的**黄色区域**填写设备铭牌参数，
铭牌照片**嵌入对应单元格**（右击图片→"嵌入单元格"）。参数必须来自铭牌/能效标识/检测报告。

### 第2步：运行工具
1. 双击 **设备能效分析工具.exe**
2. 点击【浏览…】选择填好的Excel文件
3. 点击【开始分析】
4. 等待进度条走完（几十秒）

### 第3步：查看结果
- 自动生成 **《原文件名_能效分析结果.xlsx》**（在原文件同目录）
- 每个设备sheet的"能效判定"列就是判定结果
- 判定结论含义：

| 结论 | 含义 |
|---|---|
| 1级 / 2级 / 3级 | 达到相应能效等级 |
| 未达3级 | 低于能效限定值（3级） |
| 无法判定 | 缺少关键参数（如效率、比功率），需补充资料 |
| 不在范围 | 设备参数超出标准适用范围 |

## 四、常见问题

**Q1：提示"无法判定"怎么办？**
答：该设备的判定必需参数缺失（最常见是效率、比功率没填）。补充铭牌/检测报告数据后重新运行。

**Q2：判定结果和预期不符？**
答：工具按**现行国家标准**判定。请注意：铭牌上标注的能效等级（如IE3）只是参考，
须按现行标准重新判定。

**Q3：照片会不会丢？**
答：不会。输出文件是原文件的完整副本，只修改判定列，照片、格式原样保留。

**Q4：可以在WPS里用吗？**
答：可以。Excel和WPS均可。

**Q5：判定依据是什么？**
答：每台设备的判定依据（标准号+条款）记录在结果中。详细口径见《标准判定规则清单》。
