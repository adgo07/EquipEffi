## 第一部分：豆包方案评审

### 一、值得采纳的好设计（6条）

| # | 设计 | 为什么好 |
|---|---|---|
| 1 | **状态机 + 增量处理**（未处理/已判定/待复核/人工修正） | 能评审核的真实场景就是"能自动的自动，不能自动的标记，人工补数据后再跑"。已判定行跳过、人工修正行永不覆盖——避免客户改完数据被工具覆盖的灾难 |
| 2 | **异常三重标记**（行级橙色 + 字段级红框批注 + 汇总待复核清单） | 不懂电脑的人也能一眼看出问题在哪、怎么改 |
| 3 | **计算过程不暴露**（中间计算在内存，输出只留标准值和结论） | 完全符合您"保持神秘、不易复制"的要求 |
| 4 | **17类设备各写独立判定函数**，不用通用配置引擎 | 吸取了上次过度设计的教训。各类判定逻辑差异太大，硬抽象就是灾难 |
| 5 | **标准数据 JSON + 维护端PDF提取工具**（自动标注可疑值→人工校对→生成JSON） | 18个PDF手工整理不现实，自动化+人工把关是对的。JSON可直接打开校对，比SQLite友好 |
| 6 | **Nuitka 打包**（编译为C，启动快、难反编译） | 比PyInstaller更符合"神秘性"，且杀软误报率低得多 |
| 7 | **阶段1只做3类设备**（变压器/低压电机/清水泵）打通全流程 | 比我的10类方案更稳妥，采纳——3类跑通再滚动 |

### 二、必须修正的技术错误（2条，很关键）

| # | 豆包方案的说法 | 实际情况 | 后果 |
|---|---|---|---|
| 1 | "openpyxl 保留格式、图片、批注、数据验证" | **openpyxl 读写会丢失图片和图表**（这是它的硬伤，读取时不加载图片、保存时图表被剥离） | 直接违反"铭牌照片必须保留"的硬需求。**必须用"zip补丁"方案**：openpyxl只读+算结果，用zip层只替换单元格值，图片/格式原封不动 |
| 2 | "阶段1实现变压器、低压电机、清水泵"——但清水泵是**公式法**（比转数ns→Ci常数→回归公式），是三类设备里最难的 | 变压器是"多条件查表+插值"，低压电机是"简单查表+插值"，清水泵是"公式计算+查常数表" | 阶段1建议改为**变压器+低压电机+空压机**（三种典型：查表/插值/公式），或变压器+低压电机+高压电机（同族，标准数据可复用）。清水泵公式法留阶段2 |

### 三、设计漏洞/需优化点（5条）

1. **"客户手动改等级后自己选'人工修正'状态"——对客户要求过高**。客户根本不懂"人工修正"是什么。改为：**工具对比"能效等级列当前值≠上次工具写入值"自动识别为人工修正**，状态列只给工具读，不开放给客户选（或隐藏）。
2. **增量重跑依赖"状态列"，但客户很可能把结果文件改名/删列**。防护：状态列用浅色放在最后+隐藏"异常信息"列；工具重跑时找不到状态列就按首次运行处理（全量重判但保留能效等级列的人工值——用第二条的识别逻辑）。
3. **"自动识别输入文件含状态列决定走首次/增量流程"**——流程虽好，但客户场景90%是"一次跑通"，增量是王玮内部审核时才用。GUI上应**默认全量重判**，增量作为高级选项，避免客户误操作。
4. **JSON标准数据缺乏版本/校验结构**：应内置 standard_code + version + effective_date，工具启动时校验数据文件版本与程序兼容性（防止客户拿旧数据文件配新EXE）。
5. **远程升级只留了"NAS接口"**：NAS还没有，等于没做。建议MVP做"版本号显示 + 更新说明"即可，自动更新二期再说（客户环境网络不可控，自动更新失败反而砸口碑）。

### 四、豆包方案没覆盖的坑（结合V1.11实表发现）

1. **V1.11里已经有一批公式损坏**（变压器 #REF!、潜水电泵 #REF!、鼓风机 #DIV/0!、热处理 #REF!、单元式空调 #REF!）——标准数据从V1.11转JSON时，**必须逐sheet校验数值**，可疑值按豆包"7.3标注"流程处理。我已确认：变压器/电动机/空压机/风机标准sheet质量可用；高压电机标准（237行x16378列，格式污染但数据在前12列）、永磁同步电机标准（922行，数据在A-L列）可抢救；**其余设备标准数据完全缺失**（泵公式系数、潜水泵、鼓风机、锅炉、热处理、制冷5类），需从PDF提取。
2. **热泵冷水机组sheet是"填写+标准"混合sheet**，转JSON时要把标准值（COP/IPLV各级）与填写区分离。
3. **照片列是 DISPIMG 函数**（WPS的嵌入图片格式，如 `=DISPIMG("ID_AF7FD155BFC74...")`）——openpyxl读这种单元格得到的是公式字符串，**zip补丁方案必须原样保留这些单元格不动**，绝不能覆盖。
4. **同一行有多条设备记录**（如变压器R7照明专变、永磁R5格式错误行、空压机R5）——清洗时必须处理"一行多设备""模板残留行（序号0）"的情况。

## 第二部分：清洗规则清单（结合V1.11逐类完善）

### 通用规则（所有sheet）

| 规则 | 级别 | 说明 |
|---|---|---|
| 文本清理 | auto_fix | 去首尾空格、全角转半角、去不可见字符、统一引号 |
| 数字列去单位 | auto_fix | "45kW"→45、"1.5 MPa"→1.5（按列标题识别单位） |
| 模板残留行 | auto_fix | 序号=0或无位号且全空的行→跳过不处理 |
| 必填项校验 | flag | 判定必需参数为空→待复核（每个sheet的必填项见专项表） |
| 数值范围校验 | flag | 功率≤0、流量≤0、扬程≤0、效率>100或<0、损耗<0 |
| 逻辑校验 | flag | 空载损耗≥负载损耗（变压器）、比功率与功率/流量比值矛盾等 |

### 各设备专项清洗规则

**① 变压器**（必填：变压器类别、额定容量、铁芯材质、绝缘等级、连接组标号、空载损耗、负载损耗）
- 容量：数值>0，单位kVA（填"1000kVA"去单位）
- 铁芯材质标准化：电工钢带/非晶合金（同义词：硅钢→电工钢带）
- 绝缘等级标准化：B(100℃)/F(120℃)/H(145℃)，格式校验（括号内为温升参考）
- 连接组标号格式校验：Dyn11/Yzn11、Yyn0、Dyn11 等（含"/"的合并写法保留）
- 变压器类别：**必须能精确匹配标准表名**（如"10kV油浸式三相双绕组无励磁调压配电变压器"），匹配失败→待复核（这是查表的关键维度，V1.11里用户手填容易不一致）
- 损耗逻辑：空载损耗应远小于负载损耗（数量级差10倍左右）；损耗数量级随容量增大（30kVA几十W→20000kVA上万W）
- 型号解析交叉校验：SZ11-20000/110→容量20000、电压110kV（与容量列、类别列比对，不一致→flag）

**② 低压电动机**（必填：型号、额定功率、设备效率；极数）
- **极数解析（陷阱区）**：从型号取"-"后的数字，如 YE3-225M-4→4极；**注意 355L2-4 这种机座号含数字的，绝不能取"2"**；YYE3-355L2-4→4极
- 极数列与型号解析结果不一致→flag（客户常填错）
- 效率：0~100（%），合理范围30~99；填小数（0.89）自动×100？——V1.11用%（94），按%处理
- 功率：>0；转速可不填（判定不需要）

**③ 高压电动机**（必填：电压等级、冷却方式、额定功率、设备效率、极数）
- 电压等级标准化：3kV/6kV/10kV（3.3/6.6/11归入对应档）
- 冷却方式：IC代码格式校验（IC411/IC611/IC616/IC81W等），同义词不合并（IC代码本身是标准化的）
- 极数解析：YXKK400-4→4极、YXKK400-14→14极（**高压电机极数到14+**，尾数识别与低压相同但范围大）
- 效率：合理范围90~98

**④ 永磁同步电机**（必填：型号、额定功率、设备效率、极数；表类型：异步起动/变频驱动）
- **先识别表类型**（GB 30253分异步起动、变频驱动两类，查表完全不同）——V1.11只有"表1 异步起动"，需要加"表类型"列或按sheet区分
- 极数解析：TYCX315S-4→4极；10极/12极/16极档位部分功率**标准值为"一"（不适用）**，清洗时识别
- 效率：合理范围85~98

**⑤ 空压机**（必填：设备型式、容积流量、排气压力、冷却方式、是否变频、机组比功率）
- **最高频陷阱：机组比功率 ≠ 电机额定功率÷流量**（V1.11示例：功率132kW、流量23.1，比功率7.1≠132/23.1=5.7）——企业填的比功率应是**实测机组输入功率（含风扇/控制器损耗）÷排气量**。清洗时校验：若 额定功率/流量 > 比功率，说明比功率可能填错或比功率不是实测值→flag
- 设备型式标准化：螺杆式/活塞式/滑片式（同义词：螺干→螺杆）
- 排气压力：0.3/0.5/0.7/0.8/1/1.25 MPa 档位匹配，**不在档位→按标准"靠高档"处理**（需确认GB 19153-2019第4.3条原文）
- 冷却方式：风冷/液冷（同义词：水冷→液冷）
- 是否变频：**工频/变转速查表不同**，必填且标准化（是/否）

**⑥ 清水泵 / ⑦ 化工泵**（必填：流量、扬程、转速、吸入形式、级数、设备效率；清水泵另需泵轴方向、支撑形式）
- 流量>0、扬程>0、转速>0
- 吸入形式：单吸/双吸（**双吸泵计算ns时Q取半**）
- 级数：正整数（**多级泵计算ns时H取单级=总扬程÷级数**）
- 支撑形式：管道泵/非管道泵（清水泵判定需要，V1.11有此列）
- 设备效率：合理范围30~92，**必须为实测值**（无效率数据→无法判定，不是清洗能解决的）
- 输出功率Pu：按 ρgQH 计算（Q用m³/s，总流量不除2）——V1.11已实现，工具复算校验
- 比转速ns：ns = 3.65×n×√Q(m³/s) / H^0.75，双吸Q取半、多级H取单级——**工具计算，V1.11公式正确（已用实表验证：脱盐水泵2300m³/h/45m/1480rpm双吸→ns=175.7 ✓）**

**⑧ 通风机**（必填：风机类型、压力、流量、转速、机号、进口滞止密度；介质、等熵指数）
- 风机类型：离心/轴流（**看气流方向：径向出=离心、轴向出=轴流**，客户常填错，型号可辅助判断）
- 压力分类：全压≤30kPa→通风机（GB 19761）；30~200kPa→鼓风机（GB 28381）；>200kPa→压缩机（**不在范围**）——**类别选错会导致查错表，必须校验**
- 机号：数字（No10→10），机号×100mm=叶轮直径
- 计算列（工具算）：叶轮圆周速度 u=π×D×n/60、压力系数 Ψ=pF/(ρ×u²)（已用V1.11实表验证：2105Pa/1.2/59.66²=0.492≈V1.11的0.489 ✓）
- 比转速ns计算（需标准原文确认公式）
- 介质：空气/烟气/废气等（影响密度）

**⑨ 鼓风机**（必填：流量、升压、多变效率、转速、离心级数）
- 多变效率：V1.11的公式有 #DIV/0! 错误——**需从标准原文重新实现多变效率计算**（涉及b2/D2、进出口温度压力），或改为"检测报告直接填多变效率"
- 压力分类校验：升压30~200kPa
- 判定结论是两档（GB 28381-2012）：能效限定值/节能评价值；**2026新版（GB 28381-2026）改3级制、2027-04-01实施**——标准版本问题见判定规则

**⑩ 潜水电泵**（必填：类型、流量、扬程、转速、额定功率、设备效率）
- 类型：小型（≤22kW）/大中型（>22kW）——**按功率自动分表**
- 工作温度：潜水泵在热水工况效率不同（GB 32030有温度修正？需确认）
- 规定效率容差：判定时按"规定效率-容差"比较（V1.11有ηDB、Δη列，公式已坏需重写）

**⑪ 工业锅炉**（必填：设备类型、燃料类型、容量（蒸发量或热功率）、锅炉热效率）
- **燃料类型必填**（燃煤/燃油/燃气/生物质/电——决定查表）
- 容量：蒸发量t/h 或 热功率MW（二选一，按设备类型）
- 是否冷凝锅炉：是/否（冷凝炉效率可>100%，按低位发热量）
- 热效率：0~100（冷凝炉可>100），**必须有能效检测报告，铭牌无效率**——数据来源校验（备注列应注明报告编号？建议模板加"检测报告编号"列）

**⑫ 热处理设备**（必填：设备类型、总折合重量、电炉总耗能或燃料总耗量）
- 总折合重量：t，>0
- 能耗：电炉填kWh、燃料炉填m³+热值；**燃料炉需换算kgce**（燃料系数）
- 判定按可比单耗（kWh/t 或 kgce/t），分一等/二等/三等（**推荐性标准GB/T**）

**⑬ 热泵和冷水机组**（必填：设备型式、名义制冷量、冷却方式、COP、IPLV）
- 冷却方式：风冷或蒸发冷却式/水冷（GB 19577-2024分类）——**分表关键**
- COP、IPLV：>0，合理范围（风冷2~4.5、水冷4~8）
- 名义制冷量CC：>0，分档查表

**⑭ 热泵热水机**（必填：设备型式、加热方式、制热量、性能系数）
- 加热方式：静态加热式/循环加热式（一次/二次）——**5级制判定关键**
- 性能系数COP：>0

**⑮ 风管送风式空调**（必填：类别、冷却方式、机组类型、名义制冷量、性能系数）
- 类别：风冷/水冷；机组类型：单冷/热泵——分表

**⑯ 单元式空调**（必填：类型、名义制冷量、性能系数）
- 类型：风冷/水冷（GB 19576-2019）

**⑰ 多联式空调**（必填：设备类别、名义制冷量、性能系数或能效比）
- 设备类别：分体式/整体式？单冷/热泵（GB 21454-2021按APF/COP分）——需确认V1.11类别列口径

## 第三部分：判定规则清单（结合标准原文）

### 通用判定逻辑
- 全部为"限值比较"型：**比功率、损耗、单耗类"≤限值"**；**效率、COP、IPLV类"≥限值"**
- 数据缺失或超辨识范围→"无法判定/未辨识"，进待复核清单（**绝不猜**）
- 每类输出：1/2/3级标准值 + 结论 + 依据条款号 + 备注（供审核）

| 设备 | 标准（现行/新版） | 判定方式 | 关键规则与陷阱 |
|---|---|---|---|
| 变压器 | GB 20052-2024 | 多条件查表+插值 | 查表维度：类别(28张表)+容量+材质+连接组+绝缘等级(温升)；**容量不在档位→空载/负载分别线性插值**；双指标同时达标取较严等级；损耗单位：填写W、标准kW（注意换算） |
| 低压电机 | GB 18613-2020 | 查表+插值 | 功率+极数查表；**功率不在档位→效率线性插值**；效率≥1级→1级，≥2级→2级，≥3级→3级，<3级→未达3级；适用范围0.12kW以上 |
| 高压电机 | GB 30254-2024 | 查表+插值 | 电压档(3/6/10kV)+功率+极数查表；插值同上；极数2~14+ |
| 永磁电机 | GB 30253-2024 | 查表+插值 | **分异步起动/变频驱动两类表**；功率+极数；"一"=该档不适用；效率普遍高于异步电机 |
| 空压机 | GB 19153-2019 | 查表 | 型式+功率+排气压力+冷却+变/定频查表；**比功率≤限值**（越小越好）；功率不在分档→按第4.3条处理（需原文确认）；"—"=该档无数据 |
| 清水泵/化工泵 | GB 19762-2025 | **公式法** | 算ns→查Ci常数→回归公式算各级目标效率→实际效率比较；化工泵有效率修正值Δη；**辨识范围校验**（Q/n超范围→无法判定）；轴功率≠配套功率 |
| 通风机 | GB 19761-2020 | 三维查表 | **按压力系数Ψ分表**（0.95≤ψ<1.05 / 0.25≤ψ<0.95等）+比转速ns+机号区间查效率限值；离心/轴流分表；铭牌无效率→需检测报告 |
| 鼓风机 | GB 28381-2012（现行）/ **GB 28381-2026（2027-04-01实施，3级制）** | 两档制/3级制 | 多变效率≥节能评价值→节能评价值；≥限定值→达标；否则未达标；**新版标准实施后判定口径要切换，工具需支持标准版本选择** |
