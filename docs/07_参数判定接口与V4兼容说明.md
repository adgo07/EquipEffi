# 参数判定接口与V4兼容说明

基准日期：2026-08-23

## 当前边界

- 当前入口接收单台或批量结构化参数并返回判定结果，不读取或回写Excel。
- 淘汰判定支持《高耗能落后机电设备（产品）淘汰目录》第一至第四批，并纳入用户明确提供的《产业结构调整指导目录（2024年本）》相关条目；产业条目未扩展为目录全文。
- V4空白模板只作为字段、单位、枚举和条件必填规则参考，不覆盖原文件。
- 原始输入不改写。V4字段别名、单位换算和枚举映射发生在规范化副本中，并写入`trace`的“输入规范化”步骤。

# 热泵和冷水机组双通道门槛（2026-08-30）

GB 19577-2024表1和表2是二选一的能效指标体系。表2的COPc为主指标；其`CSPF/IPLV/ACCOP`列已作为仅约束3级的固定门槛写入标准数据。接口可用`alternate_metric_value`、`cspf`、`iplv`、`iplv_c`、`accop`或V4的`aux_metric1_value`提供该替代指标。主指标达到1级/2级时不要求该3级门槛；主指标仅达到3级时，替代指标必须同时达到阈值，否则返回“无法判定”或“未达标”，并保留查表与比较轨迹。

## 使用方式

```powershell
python main.py --list-device-types
python main.py --device-type transformer --schema
python main.py --device-type transformer --example
python main.py --device-type duct_ac --json '{"category":"风管送风式空调（热泵）机组","cooling":"风冷式","mode":"单冷型","cooling_capacity":5,"indicator_name":"SEER","indicator_value":4.2}'
```

返回结果保留：最终结论、参考能效等级、实际指标、计算指标、各级标准值、逐级比较、查表记录、淘汰匹配、缺失字段、标准版本和完整轨迹。明确命中淘汰目录时，轨迹同步保存目录、批次、条目号、原文条件、来源文件和命中原因。

## V4兼容规则

- 变压器：`rated_capacity/no_load_loss/load_loss`映射为带kVA、W含义的规范字段。
- 电动机：`rated_power/rated_speed/cooling`映射为规范字段；高压电机V4的`rated_voltage`按kV换算为V并自动选表。
- 永磁同步电机：V4额定电压选择标准电压组，冷却代码选择冷却组；变频产品使用`efficiency_90_speed`判定。
- 空压机、离心泵、鼓风机、锅炉、热处理设备和潜水电泵：V4短字段名映射为带单位的规范字段。
- 清水泵完整类别映射为标准公式使用的泵型；双吸流量按半流量计算，多级扬程按单级扬程计算。
- 风管式、单元式和多联式空调：V4容量kW换算为标准表分档使用的W；动态指标按指标名称映射，不把百分比限制用于COP/EER/SEER/APF等比值。
- V4输入质量检查对额定效率、90%额定转速效率、泵/电泵效率、风机效率和锅炉设计热效率等百分数本值统一执行1～100范围（冷凝锅炉设计热效率按标准例外允许至110）；效率容差等非效率字段不套用该范围。
- 同时提供规范字段与V4字段时，规范字段优先，避免静默覆盖调用方给出的明确值。

## 当前已完成与剩余边界

- 热泵和冷水机组GB 19577-2024数据包已升级为PDF复核版`gb19577_2024_pdf_verified_v1`，覆盖表1～表8；表1/表7/表8的固定3级门槛和表5蒸汽型反向比较均保留在结果中。剩余的是现场产品样例和引用试验数据复核，不阻断结构化参数判定。
- 通风机已支持按GB 19761-2020及GB/T 1236从原始物理参数计算压缩性修正、压力系数和离心比转速，并保留表值顺序转换及结构条件修正轨迹；普通电动机直联且提供机组效率ηe、电动机效率ηm时，按式(4)换算ηr，外转子前向多翼则独立按机组效率ηe比较。
- 潜水电泵的分级偏移已实现；小型潜水电泵在流量、泵型、比转速和电动机效率齐全时可按GB/T 25409-2010附录A计算`ηSP`、`Δη`、`ηB`和`ηDB`，只接受标准精确档，不插值/外推；其余情况仍需提供引用产品标准或设计资料中的`ηDB`和`Δη`。
- 热处理燃料炉已接入表9燃料系数和燃料热值区间门禁；尚需继续扩展更多炉型规格的现场样例复核。
- 多联机EERmin已按等级分别查表，低温COP固定门槛已保留；机外静压大于0时，接口要求提供按GB/T 18837-2015或GB/T 18836-2017取得的修正后指标/修正系数，否则返回“无法判定”，不采用经验常数。引用标准的内部阻力试验表仍待资料接入。
