### 1.3 输入和结论门禁

- 所有参数叫出厂设计值、额定值或铭牌值，不使用“实测值”。
- 一般效率按百分数本值填写：98%填写`98`；允许1～100。`0.98`、`101`应拒绝或报告质量问题。
- 冷凝锅炉设计热效率允许1～110；非冷凝锅炉仍为1～100；功率因数为0～1；COP/EER/SEER/APF等比值只要求大于0。
- 电动机冷却方式必须包含`IC86W`、`IC71W(IC3W7)`、`IC416`、`IC666`。
- 结论优先级固定为：明确淘汰→淘汰；淘汰疑似但条件不足→无法判定；明确超范围→不在范围；缺少参数或标准未激活→无法判定；低于最低等级→未达标；其余返回适用等级。
- 自动备注只记录数据质量问题，不改写原始输入；能效判断写入判定说明和轨迹。

| 鼓风机 | 多变效率、逐级`b₂/D₂`、多级平均；节能评价值/能效限定值 | 不把“—”当0；GB 28381-2026当前不启用 |
| 潜水电泵 | 按引用标准计算规定效率和容差，再算三级阈值 | 不遗漏产品形式和效率容差 |
| 工业锅炉 | 燃烧方式、燃料、热值、挥发分、容量、冷凝条件查热效率 | 蒸发量和热功率均空→无法判定 |
| 热处理设备 | 电炉/燃料炉可比单耗，按炉型判一等/二等/三等 | 能源类型与能耗字段不匹配→无法判定 |
| 热泵和冷水机组 | 分级指标、固定门槛、多指标AND/OR | 不把所有类别套同一指标 |
| 热泵热水机 | 类型、加热方式、是否带泵、制热量查1～5级COP | 不输出普通设备的4/5级 |
| 风管/单元式空调 | 自动确定SEER、APF、IPLV、EER或AEER后查表 | 不保留已删除的额定出水温度列 |
| 多联式空调 | 静压修正、主指标、EER双门槛、低温COP门槛 | 多指标必须记录每个AND/OR通道 |

算法任务每次必须先写失败测试，再改评价器；结果至少核对`actual_metrics`、`calculated_metrics`、`limits`、`lookups`、`comparisons`、`trace`和淘汰匹配，不能只看最终等级。

## 6. Excel、跨平台和发布边界

当前不做以下工作，除非用户另立任务明确授权：

- Excel上传解析、批量导入和结果回写；
- “判定轨迹”写回工作簿；
- SQLite持久化；
- 全量校对册重建、PMSM重新提取或PDF全量渲染；
- wheel、ZIP、MSI、PyInstaller等全量发布构建。

允许的接口性工作：

- 保持`ApplicationApi.evaluate()`和`evaluate_batch()`作为跨平台核心入口；
- 保持`schema()`返回输入字段、锁定结果字段、允许结论和标准包状态；
- 为Linux/Android增加薄适配器，但不得在适配器中复制评价算法或读取标准JSON；
- Excel占位接口已补强为统一的`FeatureNotEnabledError`及功能名称说明；仍不得在本阶段实现Excel解析/回写或SQLite。
