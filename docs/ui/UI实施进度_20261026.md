## 环境与真实截图

- 本地原无可用Python/PySide6命令；使用bundled Python 3.12.14在项目建立 `.venv`，安装项目正式 `desktop` / `tools` 及测试依赖。实际PySide6 6.12.0；未修改系统Python。
- 截图由 `tools/ui_stage1_capture.py` 构建真实MainWindow并运行Qt事件循环，平台为 `windows`，不是HTML或离屏截图。
- 系统屏幕 `devicePixelRatio=1.5`，逻辑DPI为96，`QT_SCALE_FACTOR`未设置，即当前150%系统缩放。1440×1000窗口大于当前屏幕可视逻辑区域，使用窗口自身 `grab()`取得完整客户区；不声称所有大窗内容同时完整显示在物理屏幕内。
- [截图元数据](screenshots-stage1/capture.json)保存实际窗口尺寸、缩放和隔离数据位置。窗口客户区1440×1000、1000×700、560×420的代表截图共9张；窄窗宽表仅表内横滚、表单正文纵滚，侧栏保持可见。
- 数据目录：`outputs/ui-stage1/data-04`；截图样本项目明确为“测试数据 · 青舟示例项目”，由原泵分析服务生成一条测试记录。没有读取默认用户 `records.sqlite`。
- [首页](screenshots-stage1/home-1440x1000.png)、[标准列表](screenshots-stage1/standards-1440x1000.png)、[标准详情](screenshots-stage1/standard-detail-1440x1000.png)、[泵表单](screenshots-stage1/pump-1440x1000.png)、[泵结果](screenshots-stage1/pump-result-1000x700.png)、[窄窗泵表单](screenshots-stage1/pump-560x420.png)。
