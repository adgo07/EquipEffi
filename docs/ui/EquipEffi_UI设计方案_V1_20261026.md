# EquipEffi 设备能效软件 UI 设计方案

2026年10月26日 · V1 已确认设计基线

用户已确认总体方案并授权开始实施。执行由独立会话承担，方案设计和最终独立验收由原会话承担；执行安排见同目录《UI实施任务书_20261026.md》。

以现有 PySide6 桌面界面为基础，采用青舟家族的无侧栏首页、淡蓝业务导航、标准优先入口、紧凑专业表单与独立记录详情。保留设备能效软件的计算、自动记录和批量工作簿流程。本次交付设计正文及四张关键页面示意，未修改生产代码。

用户已确认以 EquipEffi 为准；正式产品名称沿用“设备能效分析工具”。原请求中的“能耗限额”对应另一个产品 ECQuota-Insight，本稿不混用其对标、折标系数库等业务。

### 3.2 窗口适配

主对照1440×1000；日常检查1180×800及当前默认1000×700；560×420是源码当前最小窗口，不能在美化中无意抬高。

- 宽窗：侧栏242，正文最大1440居中，短字段双列，长名称弹性伸展。
- 1000宽附近：任务卡2×2，专业表单按宽度切为单列，保留完整导航文字。
- 560宽附近：侧栏约144并允许文字换行，仍保持可见；正文边距12，标题与操作上下排列，表单单列；宽表仅在表内横滚。
- 首页始终无侧栏，窄窗卡片一列。业务详情滚动限于正文；长类别选中后另以换行摘要完整显示，不只靠tooltip。

实际Qt字体及125%或150%系统缩放需在实施时核验；本HTML仅作设计展示。

## 4 导航与任务关系

首页主入口：**标准库 → 新建分析 → 表格导入 → 分析记录**；设置在品牌栏右侧，独立于任务卡。

业务侧栏顶部LOGO与产品名；中部依次为首页、标准库、新建分析、表格导入、分析记录；底部设置。点击首页才回到无侧栏首页，业务详情保留侧栏与所属项选中状态。

标准详情的“按此标准分析”明确传入标准号与版本；未知或未开放时说明原因，不能回退到泵或沿用上次设备。返回列表恢复关键词、筛选、选中与滚动。切换设备保留本次各表单输入，不建立跨启动草稿。

首页设置进入带侧栏设置页，是本稿推荐选择，中央对此仍为OPEN。

## 5 逐页设计

### 5.1 首页

品牌区：真实LOGO、“设备能效分析工具”、一句“查询标准，完成设备分析与批量评价”。移除首页长篇标准资料和内部状态墙。

四张入口卡参考最小高180、间距14。标准库深蓝渐变、宽度约为普通卡1.47倍；其余白底，每张一个SVG图标、名称与一句用途。首页不再铺三套设备分析按钮，设备选择集中在新建页。

下方“最近分析记录”显示最近5条真实单台记录及“查看全部”。名称来自已有项目/设备字段；缺失时用真实类别，记录ID作为辅助信息。当前最近查询未构成跨单台和批次的统一时间线，不伪造混合历史；批次通过分析记录完整可达。

无数据：“尚无分析记录”及“新建分析”。读取失败：“暂时无法读取记录”及“重试”。不加KPI、继续草稿或示例业务记录。

### 5.2 标准库列表

标题下为关键词输入及唯一“标准状态”筛选。搜索覆盖编号、名称、适用对象，保留中文输入法预编辑、光标与焦点；不增加年份或软件支持筛选框。

五列固定：**标准编号｜标准名称｜标准状态｜实施日期｜软件支持**。参考列宽160、弹性名称、100、120、210，窄窗表内横滚。编号与名称都能点击或键盘打开同一详情。

软件支持列分别呈现“正式支持”“已接入，待正式支持验收”“验收候选”等真实状态；标准状态列仅表达生命周期。缺日期显示“未提供”，不从截图补值。

优先聚合现有standard_overview等读模型；扩展只读目录时必须有权威元数据及状态来源，不能扫描映射文件名就宣称已收录全部标准。可补应用层只读投影，不新建标准数据库。

### 5.3 标准详情

标题区左侧“返回标准库”，右侧“查看标准原文”及主操作“按此标准分析”。正文只有连续三个分区：

1. 基本信息：编号、名称、版本、标准状态、实施日期。
2. 适用范围：真实适用对象、条件及排除条件。
3. 标准要求：权威指标、单位、等级规则摘要与必要条件；复杂标准按相关类别展开，不将35张表堆满首屏。

不设详情页签，不显示发布单位、标准关系、来源专区或独立软件支持范围。底层来源和证据仍保留。

保留“查看标准原文”。本仓禁止把标准原件放入正式安装包；仅有有效授权链接或已有本地位置时打开，否则明确“当前没有可打开的标准原文”。不为按钮打包原始PDF，不假报打开成功。

### 5.4 新建分析共同区域

一组标题、设备选择和所选标准，候选状态就近显示；正文为基本信息、业务数据、数据检查、分析动作、结果五类内容，不变成五步向导。

分析前主按钮“分析”；运行中防重复提交。合法终态按原服务自动生成记录，完成后主操作“查看记录”，“再次分析”为次操作并说明会产生新记录。计算结果和保存状态分别显示，保存失败不声称记录已生成。

输入变化后标明“输入已变更，请重新分析”，不覆写历史记录。就近格式检查不等于业务判定，不新增“全部字段完整才能分析”的总门禁；其他/不确定类别及资料不足仍按本仓合法终态规则处理。

### 5.5 离心泵表单

单页紧凑分区，不加二级目录。

| 分区 | 布局与字段 | 业务约束 |
| --- | --- | --- |
| 基本信息 | 企业/项目名称、设备编号，宽窗并排 | 两者可选；评价日期取本机当天，不新增日期输入 |
| 产品类别 | 可搜索下拉与完整选中名称 | 保留8个正式泵型及其他/不确定类别，不默认猜泵型 |
| 设备参数 | 流量Q m³/h、扬程H m、转速n r/min、泵效率η % | 双列或单列；原字段及单位不变 |
| 类别条件 | 吸入方式、级数 | 可选时单吸/双吸用并排单选；类别唯一确定时显示只读值和原因 |
| 结果 | 最终结论、实际效率、等级限值、关键计算参数、保存反馈 | 只展示服务结果，不比较显示修约后的数值 |

遵守本仓Owner UI02决定：普通泵结果区不重新增加“为什么是这个结果”“所选标准”“标准依据”三块长说明；可读计算依据在记录详情第二页签，底层证据继续保留。

### 5.6 变压器表单

按“基本信息 → 产品类别及标准条件 → 额定参数 → 损耗数据 → 检查与结果”组织。35类正式类别及其他/不确定类别取现有input_contract；搜索只查找登记项，自由文字不能新建类别。

核心为额定容量kVA、空载损耗W、负载损耗W；电压kV、阻抗%和标准条件依类别出现。双绕组/高中、高低、中低阻抗分别输入，每个输入只承载一个数字。条件必填依契约，例如630kVA条件，不在排版层扩大为一律必填。

类别长名称换行；组合较多的标准条件保留下拉。结果分行显示空载与负载损耗、相应限值和最终等级，不汇成缺乏依据的总分。不新增温度换算、专业条件或模板列。

### 5.7 电动机候选表单

仅已授权候选装配启用；单页布局，六类电机及其他/不确定类别不变。功率、实测效率，以及随类别变化的电压、频率、极数、转速等来自motor input_contract。

实测效率旁显示“例如85%填85”，保持1～100防呆范围；铭牌效率不能代替额定输出功率下实测效率。效率口径说明保留原选项和空值语义，不默认勾选“已核实”。极数继续允许正偶数输入，不改为仅表内极数的封闭下拉；表6驱动边界与转速口径不变。

不为与泵外观一致新增当前电机契约没有承载的项目/设备编号保存字段。输入页与历史记录均准确表达候选状态。

### 5.8 表格导入

| 区域 | 内容 | 动作与反馈 |
| --- | --- | --- |
| 模板与说明 | 当前构建的统一工作簿模板，少量填写提示 | 次操作“下载空白模板”，不逐Sheet询问容量 |
| 选择文件 | 文件名、可复制路径、输出位置说明 | 选择/更换文件；输出位置按需展开，结果另存新文件 |
| 数据检查与预览 | 识别的工作表、数据行、空行、未处理工作表、真实问题位置 | 选文件自动检查；已有解析对象可提供有限行只读预览，不加确认步骤 |
| 处理结果 | 批次状态、行数/台数、结论分布、输入错误与执行失败 | 执行前“批量评价”，完成后“打开结果”，另有打开文件夹及批次记录 |

预览可见行数不能充当处理总数。轻检查没有逐字段结果时显示真实摘要，不伪造完整校验通过；逐行结论仅正式服务返回后呈现。

保留后台线程，运行中禁用重复评价与更换源文件；没有进度回调时使用不定进度，不显示虚构百分比，不提供不安全的取消。关闭时延续等待正式写入完成的机制。

换文件清除旧预览及结果关联；取消选择保留原状态。结果文件与批次记录保存分开反馈；部分完成列清已形成结论、输入错误、执行失败和未处理工作表。一个Workbook仍仅一条batch_record，不为每行生成单台记录。

### 5.9 分析记录

用“单台分析｜批量评价”分段选择分类，避免与详情页签混淆。保留两类存储与查询服务，不合并数据库。

单台表格：“设备/项目｜设备类别｜采用标准｜结论｜评价日期｜操作”。真实名称缺失时用类别；搜索仅承诺当前快照及查询支持字段，保留关键词、类别、结论、日期和加载更多。

批次表格：“输入文件｜标准/设备｜数据行数｜设备台数｜处理摘要｜保存时间｜操作”。批次搜索是拟补的只读查询能力，应覆盖全部批次；实现前不能把已加载50条内筛选标成全库搜索。

查看、双击或Enter进入独立详情；返回恢复分类、筛选和滚动。详情严格两个页签：

| 页签 | 单台记录 | 批次记录 |
| --- | --- | --- |
| 基本信息与结果 | 保存时对象、标准、日期、结论、关键指标和支持状态快照 | 文件名、标准、行数、台数、结论分布与执行结果 |
| 输入数据与计算依据 | 保存时输入、单位、参数及已有可读依据，连续分区 | 已保存工作表摘要、问题统计和已有依据；缺逐行输入时明确未保存，不补造 |

不设第三页签、审计入口或基于记录重新分析。缺字段显示“该记录未保存此信息”，不用当前映射补值。历史只存文件名就只展示文件名，不能猜路径；有可验证位置才提供打开按钮。单台Word/PDF导出没有本次已核对的完整批准链，设计不新增按钮。

### 5.10 设置

实际偏好在前：日志级别、上次使用目录；目录按当前能力只读展示，不冒充可配置默认导出目录。软件名、版本和关于在后，运行信息放次级折叠区域。长路径可换行复制，保存失败就近反馈。

不增加主题、账号、云同步、数值精度或算法开关。首页与业务壳进入同一设置页。

## 6 状态与交互

| 场景 | 表达 | 数据行为 |
| --- | --- | --- |
| 未选择类别 | 就近提示“请选择设备类别” | 不猜类别、不回退标准 |
| 无法判定 | 中文结论与实际缺项/原因 | 按合法终态规则保存，不等同系统故障 |
| 不在范围 | 中性色及必要原因 | 不伪造等级、不当成执行异常 |
| 未达3级 | 明确文字配不利状态色 | 保留独立业务结论 |
| 执行失败 | “分析未完成”及可操作说明 | 不生成伪业务结果 |
| 保存失败 | 结果和记录状态分开 | 不声称有可打开记录 |
| 结果过期 | “输入已变更，请重新分析” | 不覆写历史Record |
| 无匹配/读取失败 | 分别说明，可清筛选或重试 | 不都显示成0条 |
| 标准尚未实施 | 简短非阻断提示 | 日期不成为新门禁 |

列表检索与业务候选确认分离，打字不覆盖业务值。普通展开、条件变化不跳顶；只有主动定位错误才滚到目标。Tab按阅读顺序，Enter确认候选或打开选中行，Esc收起候选；禁用原因在邻近文字可读。单位与错误不只放tooltip。

### 8.2 执行顺序

1. 共用样式、首页、标准列表/详情、离心泵代表区，提供同轮Qt截图做一次视觉确认。
2. 沿确认语言完成变压器、电机候选、导入、记录、设置；普通排版不逐页等待。
3. 定向回归、现有CI、原生缩放检查，默认形成一个UI PR；不自行合并或发布。

当前交付为设计稿及静态示意。原生Qt截图、业务回归及DPI验收在实施阶段完成，浏览器示意不代替Windows产品验收。

### 8.3 可观察验收点

- A-01～A-07：启动无侧栏、标准入口第一、设置独立；业务及详情保留侧栏；禁用入口不可绕过；图标一致。
- A-08～A-09：以编号/名称/对象检索，只有标准状态筛选；编号和名称打开同一三分区详情；原文不可用反馈真实。
- A-10～A-12：超过100条单台、50条批次仍全部可达；详情两页签，无重做与审计入口；历史读取不重算、不漂移。
- A-13～A-15：四区导入自动检查；换文件失效、取消选择保留状态；单工作簿单批次；表单与记录规则不变。
- A-16～A-18：长类别、单位、路径、错误与按钮不截断；状态不只靠颜色；1000×700、560×420可用，抽查125%或150%系统缩放。
- 回归重点：类别锁定、未知标准、合法终态、保存失败、结果失效、线程退出、模板版本、混合批次、分页和快照读取。
- 复用tests/unit的Qt、泵、变压器、电机及批量反馈/后台线程测试。按新增行为补定向测试，不因样式变更重做全部标准真值验收。
