版本：v0.1.0　更新：2026-08-17

## 一、系统架构

```
输入Excel（企业台账）
   ↓
【A 清洗 cleaner】core/cleaner.py    读Excel→清洗/标准化/校验→params+问题清单
   ↓
【B 判定 evaluator】core/evaluator.py + devices/*.py   查标准库JSON→判定→结果
   ↓
【C 汇总 summary】core/summary.py    数量/容量统计+问题清单
   ↓
【输出 writer】core/writer.py    zip补丁写回（图片/格式100%保留）
```

三个模块完全解耦，可独立修改、独立测试。

## 三、判定逻辑速查（12类）

| 设备 | 判定方式 | 关键点 |
|---|---|---|
| 变压器 | 类别+容量查表，容量插值，空载+负载双指标 | 损耗单位W填写/kW标准；材质/连接组仅表内区分时参与 |
| 低压电机 | 功率×极数查表+功率档效率插值 | 极数可从型号解析（355L2-4→4极） |
| 高压电机 | 电压档(3/6/10kV)+冷却(IC代码)选表 | 表1~6 |
| 永磁电机 | 异步起动/变频调速分表 | 变频表按转速档查（8~28表） |
| 空压机 | 型式+变频选表→功率/压力靠档→比功率 | 比功率须实测，禁用电动机额定功率÷流量估算 |
| 清水泵 | 公式法：ns→Ci→回归公式 | ns=3.65n√Q/H^0.75（双吸Q取半、多级H取单级） |
| 化工泵 | ns→ηb(多项式)→Δη→η0→表2偏移 | Q>3000按3000；120≤ns≤210时Δη=0 |
| 通风机 | Ψ、ns计算→三维查表 | Ψ=pF·kp/(ρ·u²)；ns=5.54n√Q/(1.2pF·kp/ρ)^0.75 |
| 鼓风机 | b2/D2×级数×D2查多变效率 | 也支持手动填限定值/评价值（2024版模板） |
| 潜水电泵 | 型式×功率档→ηDB+偏移 | 3级=ηDB-Δη |
| 锅炉 | 燃料+容量档查热效率 | 冷凝炉可>100%；挥发分条件未实现（缺列） |
| 热处理 | 可比单耗=W/Gz→表8分等 | 推荐性标准；一等/二等/三等 |

## 四、如何升级标准数据（最重要）

标准更新时（如新版GB实施），只需替换 `standards/` 里的JSON文件，**exe不用重新打包**：

1. 从新标准PDF提取数据 → 整理为与现有JSON相同结构的文件
2. 用 `tools/` 下的提取脚本辅助，或人工整理
3. 校对：生成《标准数据校对表.xlsx》交给专家核对（参考`tools/extract_standards.py`的校对表生成）
4. 替换 `standards/xxx.json`，重新分发（exe+standards）

**JSON结构约定**：所有判定器从 `devices/base.py` 的 `load_standard(key)` 读取，修改结构时注意判定器兼容。

## 五、如何重新打包

```bash
python -m venv .venv_build
.venv_build/Scripts/pip install openpyxl pyinstaller
.venv_build/Scripts/python build.py     # 或直接跑PyInstaller命令
```

产物：`dist/设备能效分析工具.exe`（单文件23MB）+ `dist/standards/`。
**注意**：PyInstaller须 `--exclude-module numpy --exclude-module pandas`（本项目不用，且numpy hook有bug）。

## 八、审核口径备忘

- 缺参一律"无法判定"，绝不估算（比功率、效率等）
- 鼓风机默认GB 28381-2012（现行），2026新版实施后再切换
- 空压机功率/压力不在档位→向上靠档（GB 19153-2019第4.3条）
- 变压器损耗：填写W、标准kW，比较时统一
