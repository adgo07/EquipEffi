### 1.2 结论集合和优先级

所有设备：`不在范围`、`无法判定`、`淘汰`、`未达标`。普通设备另有`1级/2级/3级`；鼓风机为`节能评价值/能效限定值`；热处理设备为`一等/二等/三等`；热泵热水机为`1级`至`5级`。

优先级固定为：

1. 明确命中第一至第四批淘汰目录→最终`淘汰`；
2. 疑似命中但附加条件缺失→`无法判定`；
3. 明确超标准范围或标准“—”→`不在范围`；
4. 缺判定参数、标准未实施或标准包未激活→`无法判定`；
5. 低于最低等级/限定值→`未达标`；
6. 其余按标准逐等级比较。

淘汰设备参数完整时仍继续查表/计算，保留`reference_conclusion`，但最终结论仍是`淘汰`。

## 4. 标准证据卡（没有证据不能改算法）

| 字段 | 要求 |
|---|---|
| `standard_code` | 例如`GB 19762-2025` |
| `pack_id` | 运行时实际包ID |
| `status` | `extracted`/`normalized`/`verified`/`active` |
| `data_version` | 包中版本字符串 |
| 表号/公式/条款 | 可定位原文 |
| PDF页码 | 页面范围明确；未知则停止 |
| `data_id` | 稳定记录ID；没有就报告缺口 |
| 匹配轴 | 类别、容量、功率、极数、流量、压力、转速等 |
| 区间开闭 | 每个边界写`<`/`≤`/`>`/`≥` |
| 插值许可 | 只写标准明确允许的轴；否则“禁止” |
| “—”语义 | 无数据/不作要求/不适用，引用原文 |
| 比较方向 | `>=`、`<=`、AND、OR或固定门槛 |
| 计算公式 | 变量、单位、未舍入值、舍入规则和示例 |

证据优先级：PDF原文 > 已逐项复核校对册 > 粗校对Excel > 历史JSON。冲突按PDF处理；看不清不猜。

## 5. 失败测试优先（测试要证明中间证据）

测试放在已有profile测试文件，优先`tests/unit/test_device_evaluator_matrix.py`。名称必须含profile和边界，例如：

适用时至少断言：

- `conclusion`、`reference_conclusion`；
- `actual_metrics`原始输入；
- `calculated_metrics`公式结果、单位和精度；
- `limits`各级阈值、固定门槛和“—”；
- `lookups`命中/候选、表号、区间开闭、端点、插值系数、`data_id`；

- `missing_fields`与`data_quality_issues`分开；
- `standard_reference`的标准号、表号/条款、页码、pack、状态、版本；
- `trace_schema_version == "1.0"`和本回合`rule_id`；
- 早退不能清空已有输入、计算或查表证据。

最小修改原则：只改解决失败测试的评价器分支/共享证据包装；使用已有Decimal工具；不吞异常为0、不补默认物理参数、不最近档、不外推、不把“—”转0、不改原始输入。
