## 4. 最小输入契约（拟boiler-input.v1）

### 分类

Qt采用两个明确选择：产品形态与燃烧/热源类别。产品形态选“固定式蒸汽锅炉”“固定式热水锅炉”；有机热载体显示未开放，另有移动式/其他类别/不确定类别。形态已经表达固定式和水介质，不再增加重复确认框。

燃烧/热源选层状燃煤、流化床燃煤、生物质、室燃天然气非冷凝、室燃天然气冷凝、室燃油、室燃煤、电加热。煤种仅对表1/2显示；冷凝高/低位基准仅对冷凝天然气显示，避免从效率数值或型号推断。

上述8类之外另提供“混烧/燃料无法归类”兜底选择，Qt和Excel使用同一输入契约。它不是第9种可套表热源：直接进入合法无法判定路由，不要求填写某一假定燃料的煤质参数；保留备注中的燃料事实。待核实事实由维护者按主映射登记，不由运行时自动改写标准问题台账。

|规范字段|输入与类型|必要性、校验及来源|
|---|---|---|
|product_form|枚举STEAM/HOT_WATER等|决定额定压力含义、范围和D/Q；第1章|
|combustion_category|上述8类枚举及混烧/无法归类兜底|明确类别唯一表路由；兜底不选表；电加热独立规则|
|rated_pressure_mpa|十进制文本MPa|蒸汽压力/额定出水压力按形态改标签；>0；0.1、3.8边界按范围处理|
|rated_evaporation_tph|十进制文本t/h|蒸汽+表1/3条件必填，>0；不要求表2/4/电加热额外提供无用容量|
|rated_thermal_power_mw|十进制文本MW|热水范围必填，>0；表1/3按Q选列；与蒸汽D不混列|
|coal_type|烟煤/贫煤/无烟煤/褐煤|表1/2必填；再由煤质精确选子类，既定煤种不能自动改成另一煤种|
|net_calorific_value_kj_kg|十进制文本kJ/kg|表1/2及生物质必填；>0；生物质判断8374边界。天然气体积热值不占此字段，不做固定换算|
|volatile_matter_percent|十进制文本百分数|表1/2必填，0≤V≤100；标准分支端点另按源表比较|
|efficiency_basis|LOWER/HIGHER|冷凝天然气必选；其余按源表既定口径记录，不重复让用户选择|
|tested_efficiency_percent|十进制文本百分数|额定工况有效测试热效率，>0；明确接受103等冷凝低位效率，不套通用100%/110%上限。明显异常通过可见提示核查，不能私造标准门槛|
|design_efficiency_percent|十进制文本百分数|仅低热值生物质Qnet<8374时必填，>0；用于三级下限和单独限定值比较|
|device_name/model/location/user_note|可选文本|原样保存；不参与选表|
|quantity|批量正整数|必填>0，空白不默认1；单台按既有单台语义|

所有权威数值保留原始词法和规范值，拒绝float、bool、NaN、Inf、混合单位。输入0是明确数值，不能当作缺失；缺必填、非法词法和条件字段错填返回INVALID_INPUT，不建单台记录。标准范围排除优先于无关分支参数缺失：明确移动式无需再补煤质。

Qt按条件显示字段；切换类别保留名称/型号/位置/备注，清空不适用业务字段。Excel如同时填写蒸汽D和热水Q，返回明确的条件字段错误并定位列，不任意OR或选择更严/更松列。表1/2煤种与煤质不匹配属于分支无法确定，保留原输入，不静默纠正。

## 5. Canonical、Rule和Numeric设计

从固定SHA工作簿只读派生候选JSON，包含源表、源格、原字面、条件区间的开闭端点、容量轴/分界、效率基准及三级值。派生需重现78个源数值；电加热97单独记第5.2来源。主映射与001/002的软件决定作为规则依据进入可追溯版本；禁止运行时解析Markdown决定业务。

拟用EQUIPEFFI_BOILER_EXACT_THRESHOLD_V1：十进制文本→精确有理数；工作精度/工作舍入为N/A（精确阈值与整数比例单位换算）；全值≥比较；无插值、非线性、业务允差或预比较修约。沿用已验证的输入长度/有效位/指数资源防护，单独声明版本和拒绝行为。显示用源表精度，新增派生显示通常两位小数；显示值不参与判级。Profile和可执行向量满足锁定Common Core，并覆盖环境Decimal精度与Profile错误传播。

规则执行顺序：

1. 明确标准、产品形态与热源，先识别范围排除和候选未开放分支。
2. 校验该分支必需输入、数值与基准；保存原词法。
3. 表1按D≤20或Q≤14的对应单轴选小档；表3对应D≤10或Q≤7。等号均小档。表2/4无需容量分档。
4. 表1/2结合已选煤种、Qnet与Vdaf精确命中；表4区分普通天然气、冷凝低位/高位、油、煤；缺分支不借表、不插值。
5. 普通分支按η≥T1、否则η≥T2、否则η≥T3依次判1/2/3级，否则未达3级。
6. 水介质低热值生物质Qnet<8374：1/2级仍按表3；其后η≥设计效率判3级，否则未达3级。另用η≥设计效率形成限定值结果。例如小容量、设计90、测试88为1级且未达到设计限定值；两项直接显示。
7. 电加热仅按η≥97输出限定值结果，grade=None，阈值类型SINGLE_LIMIT；不复用旧“通过即3级”。

其他已分级普通分支限定值取表三级；结果契约明确grade_result与minimum_limit_result为不同维度。设计值高于一级阈值时不能排序重写阈值，更不能使用假定T1>T2>T3的通用函数吞掉001的特例。

合法SUCCESS、OUT_OF_STANDARD_SCOPE和INSUFFICIENT_DATA沿用既有终态；无法唯一选表可形成合法无法判定记录。尚未开放的有机热载体在产品路由明确拒绝，不能调用旧内核补算；输入校验失败、标准包错误、执行或数据库异常不伪装业务终态。是否保存及保存失败按现有Outcome表达，不新造Domain enum。

每次合法单台分析追加不可变Record；评价日期自动本机当天。现有input/result/reference JSON足以保存双结果及选点，无需schema迁移。历史详情用当时快照展示“基本信息与结果”“输入数据与计算依据”两个页签，禁止拿当前设计效率/表值重算旧记录。旧锅炉候选记录若无boiler-result.v1，保持原历史展示，不追改结论。
