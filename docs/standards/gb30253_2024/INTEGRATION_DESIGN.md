## 4. 插值、判级与003临时解释

### 4.1 通用直查及一维插值

功率/转速命中表列数值点时直取原值。仅在同一表、同一等级，另一轴固定且有相邻有效数值端点时，按`T(x)=T0+(T1−T0)×(x−x0)/(x1−x0)`线性插值。端点为数值源格且同一分支；不能使用破折号、区间行、被Issue排除值或其它表格值拼端点。

### 4.2 Issue 003：限定范围的600锚双轴插值

仅表8～10中`500 < rated_speed_rpm ≤ 600`按根台账当前PROVISIONAL口径处理：500 r/min取原500列；600边使用同一功率、同一等级的“>600～900”区间列作为临时600锚。功率落在两个有效源行之间时，需同表同等级四个有效值：`A=T(Pa,500)`、`B=T(Pa,600锚)`、`C=T(Pb,500)`、`D=T(Pb,600锚)`。令`u=(P−Pa)/(Pb−Pa)`、`v=(n−500)/100`，精确阈值为

`T(P,n)=(1−u)(1−v)A+(1−u)vB+u(1−v)C+uvD`。

这是对当前Owner临时口径的精确双轴数学表达，**不是标准官方解释**。四角任一为“—”、缺值或被解释排除时均不得构造阈值；不得跨表、等级、功率区间行补角。n=500仍取500点，n=600取临时锚值；600<n≤900直接使用原“>600～900”列值；n=900.001等进入原相邻速度区间，保留原表可能存在的跳变，不作平滑。该规则仅适用于表8～10和该速度段，不推广到表29、表11～28或其它速度段。

### 4.3 唯一尚未冻结的解释：003以外同时未列功率和转速

这不是普通产品选择，而是会改变正式阈值的标准解释边界。主映射[§5“可追溯的数学表达与待确认边界”](STANDARD_MAPPING.md)第2段（当前文件第121行）把“逐轴线性插值”列为Stage B候选，同时明确“本PDF未给二维计算程序、运算顺序或舍入规则”。2026-10-29[映射确认记录](../../governance/motor_mapping_confirmation_20261029.md)“建议处理”表的“600锚参与双轴插值”项，只确认Issue 003所涉600锚、同表同等级四角及精确运算；根台账[EQP-STD-GB30253-003](../../../STANDARD_ISSUES_REGISTER.md)的“软件当前处理方式/未决边界”仅覆盖表8～10、500<n≤600 r/min，状态仍为`PROVISIONAL`。根台账未另行登记003以外的一般双轴规则。因此这些证据不冻结003以外的一般双轴算法。

建议Stage C边界为：直查、单轴线性插值、原表明确区间行以及003限定区域按本设计执行；在其它区域若额定功率与额定转速同时未列，不生成正式阈值或等级，沿用现有“无可用阈值/资料不足”业务原因。只有当产品实施范围确需评价这类输入时，才先按标准问题流程登记并决定是否接受同表同等级四角精确双线性；决定须与官方标准解释分开记录。不得将003推广至其它区域，也不得把映射中的Stage B数学候选误写成已批准软件规则。

### 4.4 比较与业务状态

按1级→2级→3级选择最高满足级；每级`η≥Tg`即满足，低于3级为未满足3级限定值。等于阈值算满足。GB/T 755效率容差仅作知识，不下调阈值、不加epsilon，也不将其报告为“淘汰”。效率输入不在1～100或非法数值属于输入错误，不给能效等级；缺必要字段时沿用当前Application合法业务状态映射；超适用范围、无表列格/插值端点时须给出可追溯原因，不伪装为“未达3级”。程序/表包/持久化异常进入执行失败通道，不伪装为资料不足且不生成正式Record。

同时只读核查当前并行GB18613候选V6.3文件：仍为18张Sheet；“电动机”20列A:T、`TblMotor` A3:T103，模板身份V6.3、contract `motor-input.v3`；F为设备类别，G为V，H为Hz，I是“历史字段（已停用）”，J额定功率、K极数、L“铭牌标称最高转速”、M额定效率，配置Sheet当前下拉仅含GB18613类别。**本设计不修改、不扩展该V6.3候选**，新标准目前没有模板入口。

产品布局决定：继续用同一张“电动机”Sheet代表一种设备，不因标准数增加而机械拆Sheet；用F受控类别ID明确标准和分支，从不按额定电压猜标准。将来统一模板沿用A:T，不增业务输入列：A:E通用字段；F标准/分支类别；G额定电压(V)；H异步起动分支的50 Hz（变频/电梯分支空）；I高压分支冷却IC代码（其它类别空）；J额定功率(kW)；K极数（异步起动分支）；L额定转速（GB30253 C/D/E）或既有类别定义的铭牌标称最高转速；M额定效率(%)；N:P软件回写阈值；Q结论；R照片；S备注；T评价说明。F是机器可读类别到标准号、字段必需性、标签和表路由的唯一契约；其中包含本设计五个GB30253分支、GB30254分支以及现有`OTHER_CATEGORY`/`UNCERTAIN_CATEGORY`。后两项不路由到具体标准，分别沿用现有类别业务语义。L在UI按类别显示“额定转速”或既有类别原标签；Excel表头用“转速(r/min；按类别填写)”并在配置/说明中定义各F类别含义。I只允许精确受控冷却代码，且仅B/D/GB30254高压分支必填；低压类别留空。

共用布局符合“一类设备一Sheet”、避免新增列并便于批量。字段语义由F类别条件化，配置契约必须明确必填条件、单位和表路由。当前V6.3的I为停用历史字段、L是铭牌最高转速、F配置仅GB18613类别，因此未来标准统一模板固定采用V6.4 / `motor-input.v4`，明确把I定义为受控冷却字段并扩充F类别；**不修改本轮GB18613-only V6.3候选**。不因标准扩展新拆Sheet。

### 6.3 Excel批量、Record与快照

“配置”Sheet登记标准类别ID、中文文案、字段条件、单位和下拉数据；CI/Gate机械比对Workbook契约与Application输入契约，配置文本变化不能改变标准表值或Calculator。Reader解析后调用同一Application/Calculator，禁止工作表公式复制效率阈值、插值或判级。Writer产生新结果Workbook，不覆盖用户输入文件；沿用一个Workbook/一次电动机批次对应一条`batch_record`，逐行结果留在Workbook，不为每台设备建普通Record。初始与扩展容量策略仍需按Phase 8统一批量合同处理。

单台Qt记录和Excel批次快照均需自足保存：原始输入词法与单位、稳定类别ID、标准号/版本、分支、表号/等级、阈值源格和映射包哈希、Rule/Calculator版本、Numeric Profile ID/version、未舍入阈值分子/分母、比较与显示投影、Issue解释版本/状态。003记录其临时锚来源与`EQP-STD-GB30253-003`；旧记录不随台账以后状态变化而重解释。读取历史仅展示已保存快照，不重算或补造证据。优先使用现有`input_snapshot_json`/`result_snapshot_json`/`reference_snapshot_json`和批次记录，不提数据库迁移；若未来证明不足，另按AGENTS的Owner决策规则处理。
