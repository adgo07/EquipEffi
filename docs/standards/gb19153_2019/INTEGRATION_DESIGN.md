## 4. 六表选路及指标查找

|表|类别与边界|冷却处理|
|---|---|---|
|1|一般用喷油回转，额定输出功率1.5—630 kW，适用压力0.25—1.4 MPa|区分风冷/液冷，源表横杠保留|
|2|一般用变频喷油回转，2.2—315 kW，同上压力；实际运行转速变化，固定设定点VFD不能自动归入|区分风冷/液冷|
|3|一般往复，0.75—75 kW，0.25—1.4 MPa|标题风冷；液冷不能借风冷值|
|4|无油往复，0.55—22 kW，0.4—1.4 MPa|括号液冷值单独建分支；无明确液冷值不能借普通值|
|5|直联便携润滑，按表内额定输入功率和压力|不继承表1—4范围或冷却条件|
|6|直联便携无油，同上|与表5保持独立值|

先检查类别与明确适用范围，再检查所选表轴范围；表内使用已批准的**功率向上取档、压力向下取档**，精确命中保持原点。两轴独立选取，不寻找“下一个有数值的单元格”。不插值、不跨表、不跳过横杠、不夹取表外端点。

表1/2压力列为0.3、0.5、0.7、0.8、1.0、1.25 MPa；第1章总范围更宽不能作为外推授权。表内压力例如0.75取0.7；0.25或超过1.25而未超标准总范围的情形，按D02=A显示无法判定。功率表外按既有002不在范围，不能外推。

表5/6额定输入功率0.25、0.37、0.55、0.75、1.1、1.5、1.8、2.2、2.6、3 kW，压力0.2、0.25、0.4、0.5、0.7、0.8、1.0 MPa。实际输入功率区间属于第4.3附加条件，不能拿实测功率重新选额定行。本轮不计算该附加条件。

等级按比功率越小越好：e≤L1为1级，否则e≤L2为2级，否则e≤L3为3级，否则未达3级。任何限值缺失不填零、不产生未达3级结论。第4.3a“下一档”不得等同本次向上查表行；最大档尚待明确，不静默推算。
