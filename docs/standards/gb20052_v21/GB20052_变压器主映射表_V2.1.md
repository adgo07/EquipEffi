# 3. 必须区分的两个映射层

## 3.1 能效判定层

【标准｜第4章，PDF物理页5–6】每一级均要求实际空载损耗 `P0_test` **与** 负载损耗 `Pk_test` 分别不高于该级限值；两项逻辑关系是 **AND**，绝不是两项之和。

```text
已确认的适用性、唯一表与唯一损耗分支
→ 获得同一级 P0_limit 和 Pk_limit
→ 对 P0_test ≤ P0_limit 与 Pk_test ≤ Pk_limit 分别核验（AND）
→ 优先检查1级，随后2级、3级
→ 均不满足三级：NOT_COMPLIANT；表值不足：UNABLE_TO_JUDGE
```

【实现约定】不采用总损耗加和、平均、补偿、单项最低级或显示舍入值代替双项比较。**等于阈值视为满足**。若仅查询表值没有合格的实测双项输入，仅给出阈值，不能声明正式能效等级。

## 3.2 技术参数层及阻抗的两种角色

【标准｜各表标题、阻抗列】短路阻抗、升/降压、绕组配对、B/F/H、联结组别和特殊低压电压等在原表中具有不同作用。

|阻抗角色|涉及表|正式能效阈值处理|数据处理|
|---|---|---|---|
|A：损耗分支选组|表2的630 kVA、表27、表28|需先唯一确定分组，才能取得阈值|保留组名、额定阻抗条件、源行及组别ID|
|B：技术条件/辅助识别|表9、13升降压组合及其余非重复损耗行|不得无明文依据将阻抗测试偏差用于切换损耗阈值|独立记录和技术合规核验|

【实现约定】双绕组使用额定/设计阻抗标量；三绕组分别保存高—中、高—低、中—低三组额定阻抗。独立保留实测阻抗及试验记录（可选留痕）。**表列额定/名义阻抗并非允许偏差的判定区间**；技术合规性另按产品和试验标准核验。待确认问题见 `GB20052_DECISIONS_NEEDED.md`（D-02、D-03）。

【标准｜PDF页12、14】表9、13升/降压切换仅对应阻抗组合变化，没有第二套损耗值；【实现约定】缺少升降压字段不应阻断已唯一确定的损耗等级，但技术参数显示须注明未确定。

## 7.3 630 kVA重复两次

表2存在两个630 kVA行：

```

```

以及：

```
630 kVA + 短路阻抗6.0%～8.0%
```

所以630 kVA不能：

```

```

而应：

```
容量630 kVA
↓
确定短路阻抗组
├─ 4.0%
└─ 6.0%～8.0%
↓
再选择损耗行
```

这是**真正影响能效损耗阈值的短路阻抗分支**。

## 7.4 630 kVA的唯一选路与插值禁跨组（V21-04）

【标准｜表2，PDF物理页8／标准印刷页4】630 kVA对应4.0%与6.0%～8.0%两套不同的空载损耗值和负载损耗列。两种铁心材料×B/F/H三个温度列×两阻抗组，按项目JSON细分口径有**12种逻辑组合**；这不等于12条原PDF物理容量行（PDF只有2条）。

【实现约定】`表2 → 630kVA → core_material → thermal_class → uk_group(4.0 或6.0~8.0) → 唯一损耗行`。缺组、冲突或两组均未命中必须 `UNABLE_TO_JUDGE / BRANCH_AMBIGUOUS`，禁止首条命中或最近组替代。对于非表列容量，若插值端点跨630 kVA阻抗条件分支，禁止自动插值，需明确唯一、同条件的两个有效原表端点。

【需确认】4%和6%～8%在工程报告中如何映射产品额定阻抗的设计值及允许偏差，见 D-02/D-03；不把实测偏差当作原表选组阈值。

# 23. 线性插值：适用表与合法端点

【标准｜第4章，PDF物理页5–6／印刷页1–2】原文在物理第5页末规定普通变压器表1～28的等级限值，第6页另起段落规定新能源变压器表29～35的等级限值，随后写明：`表中未列出的额定容量产品,其空载损耗和负载损耗应采用线性插值确定。` **该句存在覆盖全部表1～35或仅承接新能源段落两种解释空间，标准原文没有逐表明确适用清单。** 因此不能把表1～35均适用写为无争议的【标准】明文；D-01 / `EQP-STD-GB20052-001`保持OPEN。

【实现约定｜待批准候选】建议仅在同表、同分支有相邻有效容量端点时，对表1～35实施线性插值；**普通表1～28的范围仍待权威解释与Owner业务决定**。这不是已经批准的生产规则，也不等于标准无条件授权外推、跨表或跨组；本PR绝不修改生产计算。

对`S1 < S < S2`：

`P(S)=P1 + (S-S1) × (P2-P1) / (S2-S1)`

`P0`与`Pk`、1/2/3级和每一温度列均**分别**插值；端点必须是同表、同介质/相数/绕组/调压/自耦、同铁心/联结/耐热级、同特殊低压组、同短路阻抗组的**相邻有效原表容量点**。缺项、原表空白、不相邻、分支不可确定，均不可插值。

# 26. 能效等级判定

设：

```
P0,test = 实测空载损耗
Pk,test = 实测负载损耗
```

相应标准等级限值：

```
P0,1 / Pk,1
P0,2 / Pk,2
P0,3 / Pk,3
```

依次判定：

|条件|结果|
|---|---|
|两项均≤1级限值|1级|
|未达到1级，但两项均≤2级限值|2级|
|未达到2级，但两项均≤3级限值|3级|
|连3级都不能同时满足|软件状态“未达标”|

【标准】明确要求各等级实测空载损耗、负载损耗均不高于相应表值。 1. GB 20052-2024 电力变压器能效限定值及能效等级

因此两项指标：

```
不能相加
不能平均
不能互相补偿
```

例如：

```
空载损耗达到1级
负载损耗只能达到2级
→ 最终为2级
```

# 28. 软件结果状态、阻断原因与优先级

【实现约定】以下是产品状态模型（**不是标准另外定义的能效等级**）。判定必须先区分标准适用性与表值是否可取得，再进行试验口径核验和等级比较。

|`NOT_COMPLIANT`|满足前述完整条件，但两项无法**同时**满足3级限值|不是不适用/无表值|
|`OUT_OF_SCOPE`|有第1章直接证据明确排除产品（包括已确认的频率/相数/容量/结构范围等）|不能由某个表无行、专用分支缺值倒推不适用|
|`UNABLE_TO_JUDGE`|可能适用，但路由分支、字段、有效限值、插值端点或测试口径不成立/缺失|不得当成3级、未达标或无条件不适用|

**求值顺序【实现约定】**：
