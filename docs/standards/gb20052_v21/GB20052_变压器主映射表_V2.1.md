# 3. 必须区分的两个映射层

## 3.1 能效判定层

【标准｜第4章，PDF物理页5–6】每一级均要求实际空载损耗 `P0_test` **与** 负载损耗 `Pk_test` 分别不高于该级限值；两项逻辑关系是 **AND**，绝不是两项之和。

```text
已确认的适用性、唯一表与唯一损耗分支
→ 获得同一级 P0_limit 和 Pk_limit
→ 对 P0_test ≤ P0_limit 与 Pk_test ≤ Pk_limit 分别核验（AND）
→ 优先检查1级，随后2级、3级
→ 均不满足三级：NOT_COMPLIANT；表值不足：UNABLE_TO_JUDGE
```

【实现约定】不采用总损耗加和、平均、补偿、单项最低级或显示舍入值代替双项比较。**等于阈值视为满足**。若仅查询表值没有合格的实测双项输入，仅给出阈值，不能声明正式能效等级。

## 3.2 技术参数层及阻抗的两种角色

【标准｜各表标题、阻抗列】短路阻抗、升/降压、绕组配对、B/F/H、联结组别和特殊低压电压等在原表中具有不同作用。

|阻抗角色|涉及表|正式能效阈值处理|数据处理|
|---|---|---|---|
|A：损耗分支选组|表2的630 kVA、表27、表28|需先唯一确定分组，才能取得阈值|保留组名、额定阻抗条件、源行及组别ID|
|B：技术条件/辅助识别|表9、13升降压组合及其余非重复损耗行|不得无明文依据将阻抗测试偏差用于切换损耗阈值|独立记录和技术合规核验|

【实现约定】双绕组使用额定/设计阻抗标量；三绕组分别保存高—中、高—低、中—低三组额定阻抗。独立保留实测阻抗及试验记录（可选留痕）。**标称/设计阻抗的选组与实测阻抗允许偏差是两个技术角色**。Owner建议以±10%匹配单值/区间，示例4.2%匹配4%组、5.8%匹配6～8%组；作为尚需核对适用产品标准的PROVISIONAL解释记录。GB/T 1094.1—2013第10章偏差随主/其他分接、绕组对及阻抗大小而变化，不能在此宣称所有类别一律±10%为标准原文；详见D-02/D-03及解释档。

【标准｜PDF页12、14】表9、13升/降压切换仅对应阻抗组合变化，没有第二套损耗值；【实现约定】缺少升降压字段不应阻断已唯一确定的损耗等级，但技术参数显示须注明未确定。

## 6.3 表1的Yyn0：630～2500kVA为合并单元格，不是空白

```

```


## 7.4 630 kVA的唯一选路与插值禁跨组（V21-04）

【标准｜表2，PDF物理页8／标准印刷页4】630 kVA对应4.0%与6.0%～8.0%两套不同的空载损耗值和负载损耗列。两种铁心材料×B/F/H三个温度列×两阻抗组，按项目JSON细分口径有**12种逻辑组合**；这不等于12条原PDF物理容量行（PDF只有2条）。

【实现约定】`表2 → 630kVA → core_material → thermal_class → uk_group(4.0 或6.0~8.0) → 唯一损耗行`。缺组、冲突或两组均未命中必须 `UNABLE_TO_JUDGE / BRANCH_AMBIGUOUS`，禁止首条命中或最近组替代。对于非表列容量，若插值端点跨630 kVA阻抗条件分支，禁止自动插值，需明确唯一、同条件的两个有效原表端点。

【工程建议，待证据复核】对可比的阻抗值，4%按±10%展开为3.6～4.4%、6～8%展开为5.4～8.8%，可分别涵盖4.2%与5.8%；但须核对额定/实测来源、主分接、容量基准及该设备实际适用的阻抗偏差条款。此处不将±10%升级成所有三绕组或全部表格的强制门槛。

# 26. 能效等级判定

设：

```
P0,test = 实测空载损耗
Pk,test = 实测负载损耗
```

相应标准等级限值：

```
P0,1 / Pk,1
P0,2 / Pk,2
P0,3 / Pk,3
```

依次判定：

|条件|结果|
|---|---|
|两项均≤1级限值|1级|
|未达到1级，但两项均≤2级限值|2级|
|未达到2级，但两项均≤3级限值|3级|
|连3级都不能同时满足|软件状态“未达标”|

【标准】明确要求各等级实测空载损耗、负载损耗均不高于相应表值。 1. GB 20052-2024 电力变压器能效限定值及能效等级

因此两项指标：

```
不能相加
不能平均
不能互相补偿
```

例如：

```
空载损耗达到1级
负载损耗只能达到2级
→ 最终为2级
```

# 28. 软件结果状态、阻断原因与优先级

【实现约定】以下是产品状态模型（**不是标准另外定义的能效等级**）。判定必须先区分标准适用性与表值是否可取得，再进行试验口径核验和等级比较。

|状态|必要条件|禁止混淆|
|---|---|---|
|`LEVEL_1`/`LEVEL_2`/`LEVEL_3`|第1章适用、表及分支唯一、阈值有效、双项实测损耗完整且口径验证通过；相应级两项均不高于阈值|不能单项等级直接当最终等级|
|`NOT_COMPLIANT`|满足前述完整条件，但两项无法**同时**满足3级限值|不是不适用/无表值|
|`OUT_OF_SCOPE`|有第1章明确排除；或【Owner软件评价边界】唯一表/分支明确后容量低于/高于该分支真实首末点|区分`OUT_OF_SCOPE_EXPLICIT`和`OUTSIDE_TABLE_CAPACITY_RANGE`；后者不是发布机构对第1章的解释|
|`UNABLE_TO_JUDGE`|可能适用，但路由分支、字段、有效限值、插值端点或测试口径不成立/缺失|不得当成3级、未达标或无条件不适用|

【实现约定】稳定原因码候选：`MISSING_FIELD`、`ROUTE_AMBIGUOUS`、`ROUTE_CONFLICT`、`BRANCH_AMBIGUOUS`、`STANDARD_BLANK`、`NO_INTERPOLATION_BRACKET`、`INPUT_INVALID`、`TEST_CONDITION_UNVERIFIED`、`OUT_OF_SCOPE_EXPLICIT`、`OUTSIDE_TABLE_CAPACITY_RANGE`。如中央已有语义等效枚举应复用，不新造冲突的通用错误契约。

**求值顺序【实现约定】**：

1. 输入规格合法性与第1章范围；证实排除→OUT_OF_SCOPE；必要事实未知→UNABLE_TO_JUDGE。
2. 候选唯一的专用表（表8/14等）先于一般表；不得因专用表容量缺点回退一般表。
3. 同表损耗分支按D-02/03/07已批准的暂用±10%软件选组；单组命中正常判级，全部不匹配→UNABLE_TO_JUDGE；多个组同时命中时，若本容量全部等级P0/Pk阈值相同则以共同限值判级并追溯全部来源，否则UNABLE_TO_JUDGE/BRANCH_AMBIGUOUS；仅容量重复不是错误。
4. 唯一表/分支容量在其有效首末点外→OUT_OF_SCOPE/OUTSIDE_TABLE_CAPACITY_RANGE；在范围内获取物理合并单元格适用值或合法插值，真空白/无可比端点/组别不确定→UNABLE_TO_JUDGE。
5. 没有双项实测损耗时只允许阈值查询，正式结果UNABLE_TO_JUDGE；温度、测试条件未知同理。
6. 与1级两项限值AND比较→若都满足为1级；否则2级、3级；否则NOT_COMPLIANT。

当同时存在多个问题时，保留完整 `reason_codes[]` 而非用“未达标”掩盖数据不足。形式与产品支持状态分离：本阶段变压器Profile仍是`POST_V1 / NOT_IN_RELEASE_SCOPE`，规则文档不能改变发布状态。

# 31. 两绕组与三绕组阻抗数据分别建模

【实现约定】双绕组额定`uk_rated_percent`与可选实测`uk_measured_percent`分离；三绕组按高—中`uk_hm_rated_percent`、高—低`uk_hl_rated_percent`、中—低`uk_ml_rated_percent`以及各自实测字段分离，不能用一列`short_circuit_impedance`取代。
