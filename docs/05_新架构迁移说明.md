# 新架构迁移说明

## 当前状态

新架构已经完成15类公共接口、17个内部评价器、标准数据仓库、判定轨迹、
桌面/Web/JSONL展示入口和V4适配器接口。旧版实现不再是运行依赖。

新代码入口为：

```text
src/equipeffi/
```

旧版 `core/`、`devices/`、`gui/`、`config.py` 和旧测试入口已经删除。
后续只在 `src/equipeffi/` 中实现新逻辑。

## 目标依赖方向

```text
presentation
    ↓
application
    ↓
domain ← application ports
    ↑
infrastructure
```

领域层不得依赖 openpyxl、tkinter 或具体数据库。

## 当前实现位置

正式代码和标准运行时资源位于：

```text
src/equipeffi/domain/evaluation/
src/equipeffi/application/
src/equipeffi/infrastructure/
src/equipeffi/presentation/
src/equipeffi/resources/
```

评价器按设备族位于`src/equipeffi/domain/evaluation/evaluators/`，目前包含变压器、空压机、离心泵、潜水电泵、工业锅炉、热处理设备、鼓风机、通风机、HVAC和电动机模块；共用输入校验、区间匹配、结果及追踪封装位于`evaluators/shared.py`，17个内部profile工厂位于`domain/evaluation/evaluator_registry.py`。统一的15类公共设备字段对照基线位于`domain/evaluation/metadata.py`，只读提供字段ID、别名、单位、类型、必填条件、边界、枚举、UI控件和V4映射；`presentation/metadata_projection.py`为API和桌面提供无Tk/Excel依赖的字段投影校验，当前已完成变压器API和桌面试点；`v4_validation.py`已增加电动机16项冷却方式、变压器四组、空压机设备类别/冷却方式、离心泵设备类别/单双吸、潜水电泵设备形式、工业锅炉设备类别、离心通风机设备类别、轴流通风机设备类别、鼓风机设备类别/是否多级叶轮、热泵和冷水机组设备类别/产品标准/机组型式/冷却热源方式/能效评价指标体系、热泵热水机加热方式/是否提供水泵以及风管送风式空调设备类别/冷却方式/机组类型/焓差类型、单元式空调设备类别/冷却方式/机组类型、多联式空调水冷式类型/设备类别的元数据回退校验，模板契约存在时仍以契约枚举为准；共享投影还会补齐旧profile缺失的V4设备参数字段。其余类型仍按契约测试逐步切换。`device_evaluators.py`仅保留兼容导出和比转速兼容钩子，不得重新在其中加入新的设备评价器实现。

根目录`main.py`只转发到包内`equipeffi.entrypoint`，不再维护第二套CLI。

## 当前边界

- 不恢复或复制旧 `core/`、`devices/` 和 `gui/` 实现；
- 根目录 `standards/`、`standards2/` 和 `template/` 仅为本机原始/校对工作区，已加入 `.gitignore`，不作为 GitHub 发布内容；运行时只使用 `src/equipeffi/resources/`；
- SQLite仓库仍为后续可替换基础设施，不进入当前运行链；
- Excel正式导入和回写暂只保留端口，当前产品以参数输入和结果反馈为主；
- 不在标准 JSON 中嵌入可执行 Python 规则。
