### 1.2 结论和等级

所有 profile 必须支持：

~~~text
不在范围、无法判定、淘汰、未达标
~~~

普通三级设备（除鼓风机、热处理设备、热泵热水机外）还允许：

~~~text
1级、2级、3级
~~~

特殊设备允许值：

| profile | 允许的等级 |
|---|---|
| blower | 节能评价值、能效限定值 |
| heat_treatment | 一等、二等、三等 |
| heat_pump_water_heater | 1级、2级、3级、4级、5级 |

淘汰设备参数完整时，可以产生 reference_conclusion；最终 conclusion 仍然必须是淘汰。

### 1.3 输入语义和数值约束

- 所有参数都是出厂设计值、额定值或铭牌标称值，不使用“实测”措辞。
- 效率用百分数本值填写：98 表示 98%。普通效率允许 1～100；0.98 和 101 必须被拒绝。
- 冷凝锅炉设计热效率按标准例外允许 1～110；非冷凝锅炉仍限制 1～100。
- 功率因数限制 0～1。
- COP、EER、SEER、APF 等比值只要求大于 0，不套用百分数效率范围。
- 数量、级数、极数等整数必须为正整数。
- 功率、容量、流量、扬程、压力、损耗、转速等物理量必须满足标准和物理正值要求。
- 不为缺失参数设置默认值，不把 80%、1 级、最近档作为默认值。
- 不把标准中的“—”解释成 0、空白、缺失、可插值值或普通无效值。
- 不外推，不取最近档，不按单调趋势自动改标准值。
- 等于标准阈值时视为达到该等级；比较方向必须来自标准。
- 不新增“设备位号”或“是否在标准适用范围”字段。

### 1.4 标准、淘汰和日期

- 标准原文 PDF 优先，其次是逐项复核的人可读校对册；粗校对表和旧 JSON 只能作历史参考。
- 标准数据状态必须按 extracted → normalized → verified → active 递进。
- 只有 active 数据包允许正常判定；active 不等于所有边界已经验收。
- PMSM 只允许 gb30253_2024_pdf_verified_v1；禁止加载旧 PMSM JSON、临时锁文件和旧清洗版 Excel。
- 当前鼓风机使用 GB 28381-2012；GB 28381-2026 已发布但 2027-04-01 实施，本阶段不启用。
- 默认淘汰口径为“高耗能落后机电设备淘汰目录第一至第四批”；产业目录仅接入用户明确提供的受控条目，不得当作全文。
- 型号淘汰必须精确匹配或有边界的系列模式匹配，附加功率、结构、年份等条件必须同时满足；模糊相似不得判淘汰。
- 标准生效日期由服务层处理，评价器不得绕过日期门禁。

## 3. 统一结果契约

### 3.1 每个评价结果必须保留

~~~text
conclusion
reference_conclusion
actual_metrics
calculated_metrics
limits
lookups
comparisons
trace
standard_reference
missing_fields
data_quality_issues
elimination
~~~

字段语义：

- actual_metrics：用户提供且通过数值规范化的设计、额定或铭牌指标。
- calculated_metrics：依标准公式计算的未舍入值和对外舍入值；必须能追溯输入参数。
- limits：每个等级或固定门槛的标准阈值，保留单位、比较方向和数据来源。
- lookups：查表命中、候选、未命中、插值端点和禁止外推证据。
- comparisons：逐等级、逐指标比较；多指标规则必须标出 AND 或 OR。
- trace：完整步骤序号、规则 ID、输入、输出、表号、端点、系数和条款。
- standard_reference：标准编号、表号、条款、页码、data_id、pack_id 和 data_version。
- missing_fields：只写真正影响判定的缺失字段，不能用默认值掩盖。
- data_quality_issues：文本、单位、枚举、数值范围和输入格式问题。
- elimination：采用口径、目录、批次、条目号、原文条件、命中/疑似命中和原因。

### 3.2 判定说明与自动备注分工

- 自动备注只描述数据质量：缺失、非法、空格、枚举错误、单位问题、互斥字段、范围问题。
- 判定说明描述能效逻辑：标准表未命中、禁止外推、缺少物理参数、阈值比较失败、淘汰命中、标准未激活。
- 不要把“需确认”或“应补充”写入数值字段。
- 不要因为自动备注存在就覆盖能效结论；最终结论必须来自服务层和评价器。

## 7. 各 profile 的判定实现检查表

### 7.1 变压器

- [ ] 完整设备类别直接匹配标准，不拆出重复的电压、绕组、调压列。
- [ ] 容量只在标准明确允许的区间插值。
- [ ] 空载损耗和负载损耗分别保留原值、单位和标准阈值。
- [ ] 同一级两个损耗必须同时达到；缺一项只能无法判定。
- [ ] 首尾档和越界保留开闭边界、候选行和禁止外推说明。

### 7.2 低压、高压、永磁同步电动机

- [ ] 效率统一为 1～100 的百分数本值。
- [ ] 类型、额定电压、冷却方式、极数、转速和功率是不同判定维度，缺失时分别保留候选。
- [ ] 查表未命中不取最近功率、极数或转速。
- [ ] 高压电机必须记录实际匹配的表组，不写死表号。
- [ ] PMSM 只加载 gb30253_2024_pdf_verified_v1。
- [ ] PMSM 表1 55 kW、12 极三档“—”命中时为不在范围，并保留三条查表轨迹。
- [ ] PMSM 变频产品按标准要求使用 90% 额定转速效率；电梯产品使用额定点效率。
- [ ] 速度、功率和结构性“—”不能被插值或转成零。

### 7.3 空压机

- [ ] 六类产品型式和工频/变频、润滑/冷却条件独立匹配。
- [ ] 机组比功率是比较指标，缺失时不能用额定功率替代。
- [ ] 压力档边界保留开闭语义；超出标准不外推。
- [ ] 往复式和无油往复式表路由不因冷却字段为空而错误阻断或放行。

### 7.4 清水泵和石油化工泵

- [ ] 输出功率、单级扬程、比转速、C1～C3、ηb、Δη、η0 分开记录。
- [ ] 双吸泵使用标准要求的半流量；多级泵使用级数换算单级扬程。
- [ ] 级数缺失时不按 1 级；若流量足够，保留流量候选和 C 值。
- [ ] 泵效率缺失时保留公式、查表、阈值和实际功率，但不生成 comparisons。
- [ ] Q、ns 的开闭端点严格按标准；Q=300 不得误切入 Q>300。
- [ ] 轻型多级、普通多级、单级和双吸类别不能互相默认替换。

### 7.5 通风机和鼓风机

- [ ] 离心/轴流公共类型路由到同一 fan profile，但保留不同标准条件。
- [ ] 压力、流量、转速、机号、轮毂比、比转速和结构修正独立保留。
- [ ] 轴流缺轮毂比不得改判不在范围，应返回缺失/无法判定并保留候选。
- [ ] 鼓风机保留多变效率、b2/D2、级数平均和三元流动叶轮条件。
- [ ] 鼓风机结论只允许节能评价值、能效限定值及四个公共结论。

### 7.6 潜水电泵和工业锅炉

- [ ] 潜水泵按产品型式路由，并保留 GB/T 25409-2010 表4 的电机效率查表。
- [ ] ηDB、效率容差和标准“—”分别存储，不把“—”转为零。
- [ ] 锅炉燃烧方式、燃料、收到基低位发热量、挥发分和冷凝条件必须同时符合标准。
- [ ] 蒸发量和热功率至少有一项；两项均空时无法判定。
- [ ] 冷凝锅炉允许效率 103，非冷凝锅炉拒绝 103。

### 7.7 热处理设备

- [ ] 炉型和规格先确定表8标准行，再确定能源分支。
- [ ] 燃料炉使用表9燃料热值系数；不得未知燃料默认系数 1。
- [ ] 电炉和燃料炉使用各自的可比单耗和单位。
- [ ] 能源类型与能耗字段不匹配时写数据质量和判定说明，不自动改写。
- [ ] 结论只允许一等、二等、三等及四个公共结论。

### 7.8 热泵、冷水机组和空调

- [ ] 产品类别先决定动态指标名称和单位，用户输入的指标名必须校验。
- [ ] 主指标、辅助指标、固定门槛和低温门槛必须按标准逐级比较。
- [ ] 明确区分 AND 和 OR；不能因为主指标达标就跳过同级辅助门槛。
- [ ] 风管、单元式和多联式产品不得共用不适用的指标列。
- [ ] 静压修正、容量开闭边界、EER 双门槛和低温 COP/HSPF 必须写入 trace。
