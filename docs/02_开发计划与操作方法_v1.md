## 一、架构总览（三阶段拆分）

```
输入Excel（企业填的模板）
    ↓
【模块A 数据清洗 cleaner】── 独立可改
    · 读所有设备sheet → 逐行清洗/标准化/校验
    · 输出：标准化数据（每台设备一个dict）+ 问题清单
    ↓
【模块B 能效判定 evaluator】── 独立可改
    · 按设备类型分发到判定器 → 查标准库JSON → 插值/公式 → 判定
    · 输出：每台设备 = 各级标准值 + 结论 + 依据条款 + 备注
    ↓
【模块C 汇总 summary】── 独立可改
    · 数量/容量统计 + 无法判定清单
    ↓
【输出引擎 writer（zip补丁）】
    · 复制输入文件 → 只改结果单元格 → 另存（图片/格式原封不动）
```

**衔接方式**：A→B→C 只通过标准数据结构（每台设备一个dict）传递，任何模块可单独替换、单独测试、单独修改，互不牵连。

## 三、工作计划（里程碑）

## 四、操作方法（每一步怎么干）

### 我的工作方式
1. **我负责全部编码**，按上述里程碑滚动推进，每完成一个里程碑立即交付可运行版本
2. **您只做两件事**：① 标准数据校对（专业把关）② 判定结果验收（人工对拍）

### 需要您配合的关键节点

| 时间点 | 您要做什么 | 怎么做 |
|---|---|---|
| M2完成后 | 校对标准数据 | 我交付 **《标准数据校对表.xlsx》**：每类设备一个sheet，列=查询条件+各级限值，**可疑值已标红**。您对照标准PDF抽查修改，在"校对状态"列打勾即可。**JSON您不用看**——我提供"Excel→JSON"转换工具，您改完Excel，我自动更新数据。校对可分批：先校4类（本期要用的），其余慢慢校 |
| M4完成后 | 判定验收 | 我把V1.11的真实数据（脱敏）跑一遍，输出判定结果表，您对照V1.11已有人工结论核对，不一致的我们逐条排查 |
| M6完成后 | 打包测试 | 您把exe+数据文件+模板装到一台干净电脑（无Python、装WPS或Office），按使用说明走一遍全流程，重点看：①照片还在吗 ②打开快不快 ③杀软报不报警 |
| 每批扩展 | 样例提供 | 您给1~2个真实项目文件（可脱敏），我用它做回归测试 |

### 标准数据校对表（Excel）说明

**为什么用Excel校对**：JSON是给程序读的"记忆"，不适合人看；Excel是您的主场。双向转换由我维护（您永远不直接碰JSON）：

```
标准PDF ──提取──→ JSON（程序记忆）──导出──→ 校对表.xlsx（您看这个）
                                              ↑
                        您改完Excel ──读回──┘  （我更新JSON）
```

**校对表长这样**（每类设备一个sheet）：

| 序号 | 表格名称 | 条件1 | 条件2 | 1级 | 2级 | 3级 | 校对状态 | 备注 |
|---|---|---|---|---|---|---|---|---|
| 1 | 表1 10kV油浸式… | 30kVA | 电工钢带/Dyn11 | 0.065 | 0.07 | 0.08 | 待校对 | |
| 2 | 表1 10kV油浸式… | 50kVA | 非晶合金/Yyn0 | 🔴0.043 | 0.043 | 0.07 | 待校对 | 可疑值：与同列差32% |

- 红色=我提取时觉得可疑的数值（跨页断裂、合并单元格错位、与同列偏差大）
- 您只需要：对照PDF改数值（如有错）→ "校对状态"改成"已核对" → 保存发我
- 已校对的行后续不再打扰您；有疑问的加备注
