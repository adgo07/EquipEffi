## 5. 结论、淘汰和轨迹检查

- [ ] 所有设备支持：`不在范围`、`无法判定`、`淘汰`、`未达标`。
- [ ] 除鼓风机、热处理设备和热泵热水机外的其余设备另有`1级/2级/3级`；鼓风机只用“节能评价值/能效限定值”；热处理只用“一等/二等/三等”；热泵热水机用`1级～5级`。
- [ ] 结论优先级：明确淘汰→淘汰；淘汰疑似但信息不足→无法判定；明确超范围→不在范围；缺少参数/标准未激活→无法判定；低于最低等级→未达标；其余返回对应等级。
- [ ] 淘汰匹配保存目录名称、批次、条目号、原文条件和命中原因；系列型号必须有边界，模糊相似不得直接淘汰。
- [ ] 淘汰设备参数完整时可计算参考能效等级，但最终能效等级仍为“淘汰”。
- [ ] 自动备注与判定说明分工正确：前者只写数据质量，后者写能效逻辑。
