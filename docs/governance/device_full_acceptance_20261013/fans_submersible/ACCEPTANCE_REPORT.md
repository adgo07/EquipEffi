## 确认缺陷：热处理装备

详见[修复前发现与精确定位](gbt36561_2018/CONFIRMED_FINDINGS.md)，相关输入SHA固定在`gbt36561_2018/defect_input_hashes.json`。

1. FS-36561-01，表6注a，PDF8/印5：距主轴端面 **300 mm** 被写为 **500 mm**。XLSX `正文表值!H90`，CSV第90行、JSON同ID条件及生成脚本同源错误。
2. FS-36561-02，表6注b，同页：圆盘直径 **>φ300 mm** 被写为 **≥φ300 mm**。XLSX `H91`，改变恰好300 mm边界。
3. FS-36561-03，表11，PDF14/印11：井式炉950℃、0.2～1.0m³升温时间 **≤1.0 h** 被写为 **≤1.5 h**。XLSX `F294`，ID`GBT36561-2018-T11-0293`，放宽原阈值。
4. FS-36561-04，表15，PDF17/印14：原表两行印 **GB/T30829.4**，与其他正文`GB/T30839.4`不一致；XLSX `H354:H361`静默统一为30839.4。应保留原表事实并登记引用差异，不能把技术推断写成标准原文。

前三项是明确值/边界错误，第四项是未标注原文纠正；均不能以既有疑点OPEN替代修复。已通知父会话交原编制者修复，本组未修改被验资产。已批准的业务解释、Golden、生产行为均未改变。
