1. 根据原页图像/文本手工建立`build_data.py`中的数值行；不读取历史JSON或旧计算代码。
2. `pdfplumber.find_tables()`取得物理几何网格；按固定几何行列坐标读取每个数值格。特殊表2续表普通段读取几何列2/4/6等，不能用第几个非空值替代。
3. `numeric_self_check.csv`记录源PDF页、印刷页、几何行列、源格bbox、目标Sheet!cell、期望/实际和方法。
4. 共402个数值比对一致；合并破折号展开3槽均匹配同一源格。合计405项MATCH，0不一致。每张表数值覆盖72/144/36/150。该比对是手工转录对源文本自核，不是独立人员逐格图像验收。
5. 全部表页（PDF4～6）图像核阅了列顺序、端点、合并、异常小表头和破折号；式1～7以PDF6～7图像确认分母、幂次及q/2位置。尚无第二执行者独立签署的逐格证据。
