## D-02/D-03 / EQP-STD-GB20052-002/003：短路阻抗单值与范围偏差

- 【标准事实】GB20052表2的630kVA有标称阻抗4%与6～8%两条不同损耗物理行；表27/28含H–M/H–L/M–L阻抗组合。GB20052本身未将所有表列阻抗统一声明实测±10%的单一规则。
- 【Owner解释｜2026-10-11】提出短路阻抗允许10%相对误差同时覆盖单值与范围；给出**4.2%→4.0%**、**5.8%→6～8%**作为示例。若相对误差为10%，点4.0的候选值域为3.6～4.4，区间6～8的候选域为5.4～8.8（这些区间是算术示例，不是独立的标准表值）。
- 【待复核的正式依据】GB/T 1094.1—2013第6.5、10章/表1以及适用的GB/T 6451、10228、1094.11和具体制造商试验数据；**不能声称“所有变压器阻抗统一10%”已在相关标准证实**。不同主/其他分接、阻抗大/小、第一/第二绕组对、自耦与否存在不同偏差要求的来源线索。
- 【映射边界】额定/设计选损耗组的输入与实测允许偏差核验要分开；只有同基准容量、同分接条件、同绕组对、明确证据才能比较。无唯一物理组则UNABLE_TO_JUDGE。状态PROVISIONAL，未授权根据扩大范围修改生产代码/JSON。

## D-06 / EQP-STD-GB20052-006：B/F/H只选设备对应列，温度修正另论

- 【标准事实】干式表2、30、32、34中B/F/H对应100/120/145℃的Pk列；第6章要求按正式试验方法测量。
- 【Owner澄清】一台设备自身绝缘等级只有一个：例如F级只对标F列，不能为提高等级再取B/H。

## D-07 / EQP-STD-GB20052-007：表27/28三绕组阻抗必须成组理解

- 【标准事实｜PDF物理页19～20】A/B/C各是由H–M、H–L、M–L三个阻抗共同确定的**物理技术分组**，不是彼此独立的三条损耗等级；B/C可能损耗相同但物理组不同。
- 【Owner专业说明】三阻抗来自同一变压器、相互耦合；在某些绕组布置下H–L接近H–M加M–L，但该近似**不是GB20052的强制等式或所有设计的严格物理关系**。组别须看三个阻抗的完整组合；完全不匹配则不能判定。
- 【重要反例】如果对表27 B组H–M=12/H–L=42～46/M–L=28～30与C组H–M=14～22/H–L=42～64/M–L=28～40**均机械施加±10%容差**，三元组例如(12.9,44,29)%可同时命中B、C的扩展区间。因此“B/C双重命中物理上绝不可能”不能作为已验证标准事实。
- 【处理边界】先按BRANCH_AMBIGUOUS/UNABLE_TO_JUDGE留痕并要求相同基准的设计技术资料。Owner提出双组命中可视为评价范围外，但**该结论仍待正式阻抗偏差与组别解释**；不能悄然把一个路由歧义认成国标不适用。状态PROVISIONAL。
