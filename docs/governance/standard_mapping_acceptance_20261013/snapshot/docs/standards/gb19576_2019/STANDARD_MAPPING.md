## 2. 适用范围、排除项与分类

【标准，第1章，印刷1/PDF3】采用电机驱动压缩机，覆盖室内机静压为0 Pa（表压力）的单元式空气调节机，以及计算机和数据处理机房用、通讯基站用、恒温恒湿型单元式空气调节机。原文并列关系保留；专用类型的静压适用口径若实际出现非0 Pa设备，应结合引用产品标准补证，不把本轮转述当新增排除规则。

【标准，同页】排除多联式空调（热泵）机组、屋顶式空气调节机组、风管送风式空调（热泵）机组。不能只按设备俗名匹配；用途与构型重叠需先确认产品类别。

【标准，表1】普通风冷单元机分单冷SEER与热泵APF，均按名义制冷量CC分7000≤CC≤14000 W及CC>14000 W；普通水冷单元机采用IPLV，同样两容量档。专用机房5分支采用AEER，基站采用COP，恒温恒湿采用AEER，表1未给这三组附加容量档。

【技术判断】普通风冷/水冷CC<7000 W在本表无匹配行，不能外推或默认套7000 W档；这不等于本标准第1章明确写了统一7000 W范围下限，也不能把该下限强加给专用分支。

【标准，第3章，印刷1/PDF3】术语引用GB/T17758—2010；3.1将能效限定值定义为规定条件下性能系数的最小允许值。前言（Ⅰ/PDF2）说明旧版节能评价值与检验规则、能效等级标注章节已删除；不得把2004版条款无说明搬入本版。

## 5. 公式、修正、插值及判级

### 5.1 等级与能效限定值

【标准】第4章按性能系数分1、2、3级，1级最高；5.1以表1的3级为能效限定值；5.4(a)标注值不得小于其额定等级阈值且应在对应取值范围内（印刷1–2/PDF3–4）。

【技术判断，由上述阈值有序性推导，待Stage B实现】设所选行阈值T1>T2>T3，正确指标值x：x≥T1为1级；T2≤x<T1为2级；T3≤x<T2为3级；x<T3低于限定值。恰好等于阈值满足该级。此区间表达是对标准规则的机械整理，不是标准中另有编号公式。评价“标注值”还是“实测值”的业务操作须在Stage B明确，不能拿实测允差悄悄更改标签等级。

【标准】5.4(b)实测能效值≥标注值×95%；5.4(c)实测季节耗电量计算值≤标注值×110%；5.4(d)标注额定制冷量和实测值均处于额定等级对应制冷量范围（印刷2/PDF4）。这三项与5.4(a)分别检查，95%不是T1/T2/T3折扣，110%不是能效指标容差。单项失败不能被其它单项合格抵消。

### 5.2 非数值技术要求

【标准】采用电辅助加热的产品须能够手动开/闭，并在明显位置显示其工作状态（5.2）；室外干球温度≥0℃时不得自动开启电辅助加热（5.3）。两者与等级表不同维度，仅查表不能声称产品全部技术要求合格。

### 5.4 数值表达边界

本PDF阈值保留2位小数，系数1.077、0.914按原文3位，95%与110%保留原始含义。表格显示精度不是比较舍入规则；正文未指定额外业务舍入或epsilon。依locked Numeric规则，Stage B需声明本Profile的数值策略，不继承Pump Decimal50。工作簿用数值单元格加0.00显示，CSV保留字面；本次不把JS binary float变为正式业务权威。
