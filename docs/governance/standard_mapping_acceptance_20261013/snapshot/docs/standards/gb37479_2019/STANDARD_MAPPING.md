## 2. 适用范围、排除项与分类

【标准，第1章，印刷1/PDF3】电机驱动压缩机，室内机静压大于0 Pa（表压力）的上述机组。不能把静压=0包括进来。本标准未给整标准的名义制冷量最大值，各表末行开区间不得人为截断。

【标准，第3章/PDF3】术语继承GB/T 18836与GB/T 25128—2010；3.1能效限定值是在规定工况下性能系数最小允许值。小焓差/大焓差不是由本文件给出数值切点，必须从适用试验依据确认，不能用冷量或名称猜测。

【标准】表1分风冷单冷（SEER）、风冷热泵（APF）、水冷（IPLV）；表1水冷未分单冷/热泵。表2为全新风，风冷/水冷（水环式）各有大小焓差（EER）。相同值及相同容量区间仍保留不同物理分支。

【技术判断】不满足上述设备/驱动/静压范围时应区分不适用与输入非法；设备身份无法确定属于资料缺失，不能默认选表1。未在正文列出的其他排除条件不得从旧代码补入。

## 5. 公式、修正、插值及判级

【标准，第4章及5.4a】1级最高，指标越大能效越高，标注值不得低于额定等级阈值且须在该等级取值范围内。【技术推导】对选定同一分支行阈值T1>T2>T3，可表达为x≥T1为1级，T2≤x<T1为2级，T3≤x<T2为3级；x<T3为未达3级。该区间表达是对条款的数字化，不是原文编号公式；必须明确x是标注值还是合规实测报告值，不能混用。

【标准，5.1】原文最低限定值只引用“表1”3级，同时提及两类设备。【需确认，请求A】不得直接称表2的3级已被5.1正确引用；表2等级查表可保留，全新风最低限定值合规结论待决定。也不从未达3级自动推出淘汰目录结论。

【标准，5.4b/d】实测能效≥0.95×标注能效，实测耗电量计算值≤1.10×标注值，等号均允许。95%是标注一致性允差，不能据此把等级阈值乘0.95；110%也不能施加到所有输入。5.4c须检查标注/实测冷量是否仍在对应容量范围，不能只对能效比值做允差。

【标准，6.1a】风冷空调机SEER的29℃额定/中间/最小能力试验可选做，或由35℃相应能力的实测制冷量乘1.077、实测消耗功率乘0.914获得。文字关系Q29=1.077×Q35、P29=0.914×P35仅是条文展开，无原文公式号；不是完整SEER公式，不适用于APF/IPLV/EER的任意替换。

【标准，6.1b】水冷空调机耗电量不计冷却水系统水泵和冷却塔风机耗电量。不能扩大成任意辅机均不计。

【标准，6.1/6.3】实测值保留两位小数。【需确认，请求B】本PDF未列舍入模式，不能自行定half-up/half-even或借用Pump Profile；外部测试及静压修正的公式、工况、参数仍需原文补齐。此工作簿2位格式只用于保留源表表示，不承担正式计算舍入。

【标准】表内是容量区间常数，没有线性插值或外推授权。容量>最高切点使用原表明示末档，不叫外推；不允许跨物理分支插值。
