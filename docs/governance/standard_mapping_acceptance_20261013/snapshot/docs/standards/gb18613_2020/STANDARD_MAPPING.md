## 5. 插值、修正与判级

【标准，第4章】各等级在额定输出功率下实测效率不低于表1～6；1级最高。表中未列额定功率值可用线性插值确定效率。

【技术判断：第4章的数学展开，原文无公式号】在同一表、同一极数/转速分支、同一等级内，相邻且均有数值的功率端点P₀、P₁，P₀<P<P₁：

`ηg(P) = ηg(P₀) + (P−P₀)/(P₁−P₀) × [ηg(P₁)−ηg(P₀)]`

功率单位必须统一；精确表列功率直接取源值。表1中250<P<315以250和315区间起点为端点；315≤P≤1000直接取末行。不同表/极数/转速不可混插。标准只授权功率线性插值，未授权按转速插值、取最近功率或超范围外推。缺端点时不能通过公式制造值；疑点保持【需确认】。

未经容差调整的阈值比较结构：η≥T1则达到1级表值；否则η≥T2达到2级；否则η≥T3达到3级；否则低于能效限定值。等号属于达到该阈值。这个比较关系来自“不低于”；**最终判级如何结合§4容差尚有R03，不能把本段当作已完备正式软件判级规则。** 只满足某个等级表值，不意味着§5.1所有产品性能均符合，也不直接推出“淘汰设备”结论。

【标准，第5.2条】能效限定值为3级规定。标准未在本版定义旧版目标能效限定值、节能评价值（前言说明删除），不得沿用旧版字段语义。

【需确认】表6原区间保留。500/700/1000端点处理见R02，不先实现开闭约定；1300不属于>1300列。R04的72.0仅为原文照录，不认定笔误，不做改值。
