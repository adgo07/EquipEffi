## 2. 适用范围与分类

【标准】第1章（印刷1 / PDF5）：适用于**连续工作制**、**一般用途或防爆用途**永磁同步电动机，分为：

|分支|供电及电压|额定功率|极数或额定转速|冷却条件|
|---|---|---|---|---|
|A 低压异步起动三相|50 Hz三相交流；≤1140 V|0.55～1000 kW|2～16极|范围条款未附冷却方法清单|
|B 高压异步起动三相|50 Hz三相交流；3 kV(3.3 kV)、6 kV、10 kV|200～2000 kW|4～12极|以下三组之一|
|C 低压变频调速|变频电源；≤1140 V|0.55～1250 kW|45～6000 r/min|范围条款未附冷却方法清单|
|D 高压变频调速|变频电源；3 kV(3.3 kV)、6 kV、10 kV|≥200 kW，范围条款无上限|45～3000 r/min|以下三组之一|
|E 电梯用|变频电源；≤1140 V|0.55～110 kW|按表29速度分组|范围条款未附冷却方法清单|

高压冷却三组：W＝IC81W、IC86W、IC71W(IC3W7)；S＝IC411、IC416；A＝IC511、IC611、IC616、IC516、IC666。这些字母仅为本映射缩写，不新增标准分类。

【标准】第3章（PDF5）：异步起动依靠起动绕组产生的异步转矩；变频调速由变频装置驱动；能效限定值是在规定测试条件下允许的最低效率。

【技术判断】不能把普通异步电动机套入本标准，也不能只凭型号名称猜永磁/起动方式。电梯专用分支应保持专用工况与表29，不与通用变频分支混算。超出以上范围时不应强行找最近表；不新增本标准没有明确写出的防护等级、安装方式、环境温度排除项。

## 5. 插值、修正和判级

### 原文要求

【标准】第4章/PDF6：三级能效，1级最高；规定试验方法下的实测效率不应低于表1～29规定。实测效率容差符合GB/T755。规定范围内未列额定功率/额定转速以**线性插值**确定效率。第5章明确能效限定值对应第3级（变频表10、13、16、19、22、25、28；其余表的3级列）。

### 可追溯的数学表达与待确认边界

【技术表达，非原文编号公式】本标准没有独立编号计算公式。对同一分支、同一等级、另一个坐标固定且两端均有有效限值的点x₀≤x≤x₁，线性插值写为：

`T(x)=T₀+(T₁−T₀)×(x−x₀)/(x₁−x₀)`。

当功率和转速均处于数值点构成的矩形内时，逐轴线性插值可用作Stage B候选表达（四角均须存在、同一表/等级）；本PDF未提供二维计算程序、运算顺序或舍入规则，正式Numeric Profile与实现约定尚未设计/批准。不能把Pump Decimal50直接移植为标准规定。

明确落入功率区间行或转速区间列时，使用该区间原值。跨区间缺失锚点的情况须按R3澄清，尤其500<n≤600 r/min。短横线、0.0疑点及未知极数不能作未经确认的插值端点。本次整理不授权外推、跨极数/冷却/电压插值；≥3150 kW行是源表明确覆盖，不是外推。

【判级表达】在适用性、工况、所需表限值和容差解释均成立的前提下，按1→2→3级比较，`η≥Tg`满足该级表列要求；等号满足“不应低于”。低于3级表示不满足能效限定值，不自动等于设备已被淘汰。**R2未确认前不把“忽略容差直接比较”写成正式完整算法**，本映射不自行制定epsilon或把显示舍入值用于判级。
