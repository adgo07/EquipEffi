## 请求 001：静态加热 H=10 kW 的路由缺口

- 候选编号：`EQP-STD-GB29541-001`；类型：`MISSING` / `AMBIGUITY`。
- 【标准原文事实】表1的静态加热行位于 `H<10`、普通型组；`H≥10` 组只有一次与循环加热。4.2写“制热量大于10 kW”的静态加热参照“10 kW以下”的静态加热指标。
- 【技术判断】表1与4.2没有明确覆盖恰好10 kW静态加热，不可静默把“大于”改成“大于或等于”；“以下”亦不能覆盖表1明确的小于边界。
- 【建议实现，未批准】未获解释时保留为分支无法唯一确定；候选采用普通型静态行须Owner明确决定或补有源解释。
- 影响：恰好10 kW静态产品等级、5级限定值和2级节能值。
- 候选：B-10（9.99、10.00、10.01 kW普通型静态）、B-11（额定/实测跨10 kW）。
- 确认程度：仅确认文义缺口，没有发布机构解释或Owner决定。
