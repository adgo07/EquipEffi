## 2. 适用范围、排除项及术语

【标准】第1章（PDF3／印刷1）要求：电动机驱动、蒸气压缩制冷循环、以空气为热源、以提供热水为目的。暂不适用水源式。不能因名称含“热泵”即纳入，也不能把水源式强行映射为空气源。

【标准】第3.1/3.2条：能效限定值、节能评价值均为名义（额定）工况下的性能系数最小值；第3.3/4.1条：按实测COP分五级，1级最高。

【标准】型式分普通型、低温型；加热方式分一次、循环、静态。H≥10 kW的循环加热再分是否提供水泵。分类术语与试验方法依赖第2章所列GB/T 21362—2008、GB/T 23137—2008；本PDF没有完整温度工况、COP测定公式或型式判别定义。对应依赖缺口见登记请求004，不能补造环境温度或依据常识分类。

## 5. 公式、修正、插值与判级

### 5.1 指标比较

【标准】第4.1条按实测COP和表1判级；第5章明示COP实测值≥5级值；第6章节能评价值是2级值，结合第3.2条的“最小值”定义。

【技术判断：按表1有序阈值写成明确区间】设已唯一选行的1—5级下限分别为T1…T5（递减），C为符合测试要求的两位小数报告COP：

- C≥T1：1级；T2≤C<T1：2级；T3≤C<T2：3级；T4≤C<T3：4级；T5≤C<T4：5级。
- C<T5：低于能效限定值，不产生虚构“6级”。
- C≥T5满足该项能效限定值；C≥T2达到该项节能评价值。两者不能代替全部产品合格性／认证结论。

等号进入对应较高等级，不设业务epsilon，不用95%放宽表1阈值。表1是分组常数，不需要插值；原文未给出插值或外推规则，不自行创造。

### 5.2 标注一致性（4.3，单独于实测等级输出）

【标准事实转写为不等式；本标准无编号公式】

|检查|不等式／条件|边界|
|---|---|---|
|能效标注范围|标注COP位于其额定等级所对应COP区间|区间同5.1，1级无上限|
|COP偏差|C实测≥0.95×C标注|等于95%满足|
|制热量范围|标注额定制热量与实测制热量均处于对应的额定制热量范围|通常按表1 H<10／H≥10，静态参照需保留其特殊性|
|制热量偏差|H实测≥0.95×H标注|等于95%满足；跨10 kW即使比率满足也不能忽略范围条件|
|功率偏差|P实测≤1.10×P标注|等于110%满足|

资料仅足够判实测等级时，不得声称4.3全项满足。4.3不满足也不能回写表1实测等级。不得用COP标注值代替COP实测值或把标注允差当能效等级容差。

### 5.3 测定与数值约定

【标准】第7章：提供水泵时耗电量计入水泵；带标配水箱按GB/T 23137—2008测试且计入水泵能耗；不带标配水箱按GB/T 21362—2008；储热性能满足相应标准；COP实测值保留两位小数。

【需确认】本PDF没有编号COP计算式，不在此写“COP=制热量/功率”作为已完整复现的测定算法；测试能耗边界、时间区间与工况须读引用原文。未给出的温度不可猜测。多于两位COP修约方法未定，见请求003。当前边界候选只使用已报告两位小数COP；这不批准输入截断或自动修约。Numeric Profile待后续证据设计，本任务不移植Pump精度。

### 5.4 检验规则（第8章）

能效限定值是出厂检验抽检项目。先抽1台测试，若不满足则再抽2台，后两台实测值均应满足规定要求，否则判该批不合格。不得以3台平均值替代“后两台均满足”，也不把试样能效等级与批检验结论混为一项。
