## 1. 身份与当前依据

## 2. 适用范围、排除项与分类

【标准】第1章（印刷1/PDF3）：以煤、天然气、油、生物质为燃料或电为热源，以水或有机热载体为介质的固定式锅炉，并满足下列对应分支：

|产品形态|范围边界|
|---|---|
|蒸汽锅炉|额定蒸汽压力≥0.1 MPa且<3.8 MPa|
|热水锅炉|额定出水压力≥0.1 MPa，且额定功率≥0.1 MW|
|有机热载体锅炉|额定介质出口压力≥0.1 MPa|

不得将蒸汽压力的3.8 MPa上限传播到另两类。移动式、未列热源/介质及不满足上述范围者不属于本标准已明确范围。混烧燃料或不能唯一归类者不能凭最接近燃料直接套表；需具体事实后登记处理。

【标准】3.1：限定值是标准测试条件、额定工况下允许的最低热效率。3.2：燃气冷凝锅炉须连续凝结烟气水蒸气并有效利用释放的汽化潜热，不以设备营销名称代替定义。第4章等级1最高，3最低，且以满足初始排放浓度要求为前提。

## 5. 公式、修正、插值及判级

【标准】本标准无编号计算公式、无插值算法、无容量外推、无修约/允差规则。表1/3直接按容量区间，表2/4不按容量分档；不得擅自插值。试验效率按GB/T 10180测试，燃气冷凝可按NB/T 47066（第6章）；本次未取得并核验两份引用全文，不从热输入/输出原始读数再推新测试算法。

【由第4章不低于逐级推导】普通表列分支，设各级阈值T1>T2>T3：η≥T1为1级；T2≤η<T1为2级；T3≤η<T2为3级；η<T3不达到表列三级。等号属于达到该级。前提条件和限定值例外必须同时保留，不能只返回效率等级而丢掉未满足的前提。

|限定值分支|标准要求|输出边界|
|---|---|---|
|水介质、采用余热回收有机热载体|η不低于表1～4三级（5.1）|普通情形用同基准三级；特殊交叉情况见请求A|

低位/高位效率按相同基准分别选值，括号不是允差；不要求将一份低位效率同时与高位阈值比较。标准未给软件Numeric Profile，不照搬Pump Decimal50，不添加业务epsilon，不自行先修约再比较。

## 6. 无法评价及结果

候选输出事实包括标准版本、适用性原因、表/分支/等级阈值、效率口径、限定值及依据、各项比较和未决原因。正式enum/Record设计留Stage B。

- 范围排除：明确不满足第1章的对象。
- 资料不足：必要额定参数、煤质、效率口径或特例设计值缺失；零值和未提供必须区分。
- 资料冲突/分支不唯一：煤种标签与化验条件矛盾、D/Q路由矛盾，不能凭近似分支求结果。
- 输入非法：无法解析的数值、非有限数、负压力/容量等，不等于标准低效。百分数>100不能一概非法，冷凝分支有103%。
- 前提/解释未完成：见请求A/B；不把尚未确认口径包装为正式判级。
- 系统/文件读取异常：执行错误，不能伪装成业务资料不足。
