## 3 统一 Excel 版本与兼容设计

### 3.1 三类版本分开

1. 工作簿模板身份与修订：描述一份正式全设备模板资产，不以文件名作为唯一识别方式。
2. 每设备 Sheet 的结构/输入契约修订：描述字段 ID、列映射、单位、选项、必要输入及读写结构；设备名和可见 Sheet 名不能成为唯一机器身份。
3. 实际评价标准、数据包、计算器版本：由实际执行链提供，不能从模板版本推断业务真值。

复用现有 V6_TEMPLATE_IDENTITY、模板配置与构建入口，确定一个机器可读的模板发布清单作为维护入口；其他嵌入元数据和模板投影由它生成或机械校验。不得再建人工同步的第二份业务规则表。具体落点先由 Excel 执行线给出小型设计交验收方核对。

### 3.2 兼容规则

- 当前 V6-20261005 作为明确 legacy baseline 保留；原始 Owner 模板和现有正式资产不覆盖，结构有变化时产生新修订和来源记录。
- 导入同时验证已声明身份、Sheet 契约、实际表头/单位/字段。用户填写值后整本文件哈希改变是正常的，不用空白模板哈希封锁正常填写。
- 已确认兼容版本直接读；需要迁移的版本仅通过明确转换读取并另存；未知/不兼容结构清楚报错，不猜字段、单位或忽略版本冲突。
- 对没有版本标记的既有模板，仅允许明确、经过回归的旧结构识别；不能宽松接受任意相似工作簿。
- 支持状态由软件实际能力控制；Sheet 存在不代表已支持。未支持设备不计算，内容保留；当前只接通泵，不将其他设备旧公式结果视为正式结果。
- 导出新工作簿，保持未处理 Sheet 的顺序、业务内容、公式与样式；未授权部分不因全量重存而漂移。
- 结果追溯记录模板身份/修订、处理 Sheet 契约及实际标准实现版本，优先使用现有快照/结果元数据，不为此预建数据库 migration。
- 正式模板随完整软件版本提供。用户只导出一个当前模板，无需逐 Sheet 选择版本、容量或升级标准包。

### 3.3 新设备接入

已批准依据与软件支持流程完成 → 增量修改该设备 Sheet 契约/适配 → 统一工作簿生成新修订 → 验证新设备及全部已支持 Sheet → 检查未处理 Sheet 不漂移 → 合入软件。

现阶段泵验证至少包括已批准29条案例、数量正整数、未确定类别、十进制入口、单位改动拒绝、限值完整输出、旧版兼容及批次记录语义。容量/读写路径改动时复验少量/100/1000/10000行；纯文字不重复容量压力测试。
