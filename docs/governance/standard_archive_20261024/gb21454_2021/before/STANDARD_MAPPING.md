## 2. 范围、分类及术语

【标准】第1章（印刷1/PDF3）适用风冷式或水冷式冷凝器的多联式空调（热泵）机组以及低环境温度空气源多联式热泵（空调）机组。未给全局容量上下限；本文件未列独立的排除清单，不能自行增加其他标准的容量/用途边界。

【标准】3.1定义规定工况下APF、SEER、IPLV(C)或EER的最小允许值，并有“单冷只考核SEER”句；与表1附加EERmin条件的关系见登记请求R1，不能隐去该句。3.2低温机组采用电动机驱动压缩机，可在不低于−25℃环境制取热风；3.3 EERmin指只开一台最小制冷量室内机稳定制冷时，制冷量/消耗总电功率。EERmin不是名义全负荷EER。

【技术判断】分支应首先依据产品物理类型与试验资料，不以数值大小猜测风冷/水冷/低温。水环、地埋管、地下水保持独立；普通热泵与低温热泵不混用APF/HSPF。设备是否属于此范围不能确认时，保持分类资料缺口，不擅自挑选最有利表格。

## 5. 判级、技术要求与公式

### 5.1 分级及限定值

【标准】4.1为3级，1级最高；4.2～4.5实测指标“不应小于”对应表值，等号满足。5.1能效限定值为所对应类型三级指标。表1/2小容量两指标均满足；表3不同类型对应不同指标；表4HSPF分级同时满足两个COP共用门槛。

【技术判断，待Stage B确认输出】按1→2→3顺序查全部适用指标可表达最高满足等级。未满足三级应保留“不满足限定值”事实，不能伪称四级或直接创造“淘汰”结论。能效等级、标注允差和其他技术符合性应分别报告，不能只看一个比值宣布整机全部符合。本文件未单列“淘汰”政策结论。R1/R2未决处不转为正式算法。

【标准】5.2待机≤15W，容量等号属于受约束一侧。5.3电辅热可手动开闭并明显表达工作状态。5.4普通多联机室外干球≥0℃不自动开启；5.5低温多联机≥−20℃不自动开启，用户选配且预留接口且由机组控制的辅助电热，说明书须给开闭方法。

【标准】5.6a标注值不小于额定等级阈值且处于该等级取值范围；5.6b实测≥标注×95%，两者按0.01整倍数；5.6c标注容量与实测容量都在对应名义容量范围；5.6d实测计算季节/全年耗电量≤标注×110%。95%与110%是各自的核查，不是把等级表阈值打折。标注范围交界和修约口径须保留R2，不能以页面显示四舍五入代替正式比较。

### 5.2 全部编号公式

`tA=−20, tB=−12, tC=−7, tD=2, tE=7`（℃），与表A.1/A.2一致。`n_j`是对应表A.3/A.4的小时数，求和不能把两类时数合并。以下为公式忠实转写，不是生产计算器。

|公式|表达与条件|源定位|
|---|---|---|
|A.1|Lh(tj)=φful(t0)×(tj−toh)/(t0−toh)。t0=−12℃；toh户用15℃、工商业13℃；φful(t0)为名义制热量明示值W|A.1，印刷6/PDF8|
|A.2|HSPF=HSTL/HSTE|A.3.3，印刷11/PDF13|
|A.3|HSTL=Σ[Lh(tj)×nj]，量纲Wh|同上|
|A.4|HSTE=Σ{[(Lh(tj)−PRH(tj))/COPbin(tj)+PRH(tj)]×nj}，量纲Wh|同上|
|A.5|当tj<−12℃且Lh(tj)>φful(tj)，PRH(tj)=Lh(tj)−φful(tj)；φful(tj)为该温度实测制热量。未给五点容量到所有bin的方法，见R3|同上|
|A.6|四相邻点间COP线性计算与E点以上沿D/E斜率延长，完整五支见下|同上|
|A.7|C、D、E试验制热量**超过**要求负荷110%时，COPbin(tk)=COPDH(tk)×[1−CDH×(1−LF)]；CDH试验获得或取0.25|同上|
|A.8|CDH=[1−COPcyc/COPmin(7)]/(1−HLF)|同上|
|A.9|LF=(LD/100)×QFL/QPL；LD为建筑负荷率百分数的数值，QFL为名义明示制热量、QPL为部分负荷实测制热量|末页无印刷页码/PDF14|

【标准】A.6的五支（保留原区间不等号）：

1. `COP_A+(COP_B−COP_A)/(tB−tA)×(tj−tA)`，`tA<tj≤tB`。
2. `COP_B+(COP_C−COP_B)/(tC−tB)×(tj−tB)`，`tB≤tj≤tC`。
3. `COP_C+(COP_D−COP_C)/(tD−tC)×(tj−tC)`，`tC≤tj≤tD`。
4. `COP_D+(COP_E−COP_D)/(tE−tD)×(tj−tD)`，`tD≤tj≤tE`。
5. `COP_E+(COP_E−COP_D)/(tE−tD)×(tj−tE)`，`tj>tE`。

【技术判断】共享端点若端点COP一致，两侧公式结果相等；不应通过改写原端点制造差异。第5支是标准明确的延长，不能笼统“禁止所有外推”；标准发生时间表只需到14℃或12℃，不能自行延伸气候范围。A.6未给tj≤−20℃计算支；−20℃为试验点，季节表从−19℃开始。缺端点、分母零、HLF=1及非正能量等是后续输入/公式域校验候选，不以任意默认值掩盖。

【标准】A.8/A.9符号：COPcyc与φcyc按GB/T18837—2015 B.3.3.11；COPmin(7)与φmin(7)按B.3.3.6；HLF=φcyc/φmin(7)。引用全文本次未核验。A.5季节计算的补充电热与5.5产品控制试验属不同叙述层次，不能因控制温度门槛直接删除A.5，也不据此批准实际控制行为。
