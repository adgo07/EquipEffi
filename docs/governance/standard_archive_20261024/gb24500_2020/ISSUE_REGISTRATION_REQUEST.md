## 请求 A：特殊限定值与等级、交叉条件的组合输出

- 建议编号前缀：`EQP-STD-GB24500-`；类型：`IMPLEMENTATION / AMBIGUITY`。
- 标准：GB 24500—2020《工业锅炉能效限定值及能效等级》；定位：第4章（印刷1/PDF3）、表3后段及5.1（正文第4页/PDF6，原页未显示页码）。
- 【标准事实】低位发热量 <8374 kJ/kg 的生物质锅炉限定值不低于设计热效率，其他等级仍按表3；仅为有机热载体锅炉换热时热效率不低于设计值。第4章另列三级等级制度，第5.1要求水介质和采用余热回收的有机热载体锅炉不低于表1～4三级。
- 【技术判断】设计值可能高于二级或一级门槛，造成“达到表列等级门槛但未达到设计限定值”；低热值生物质与有机热载体余热回收条件交叉时也须明确限定值优先关系。不能自行把三级限值固定为表列值，也不能静默修改一级/二级阈值。
- 【建议实现，需确认】分别保留表列等级阈值满足情况和适用限定值满足情况；由 Owner 确认最终等级/合规输出及交叉条件，不以排序或 max/min 猜测。相关结果字段留到 Stage B。
- 软件当前处理：本任务未修改或确认既有实现；Mapping 明确保留需确认。
- 影响：特殊锅炉最终结论；未来 boiler 限定值与判级规则。候选：BC-14～BC-17。
- 证据：原PDF SHA、PDF6原图定位见 SOURCE_AND_VERIFICATION.md；无外部官方解释，无已批准Golden变化。
- 首次发现/更新：2026-10-13；请求登记后对应解释仍需确认。
