## 可复现操作

使用`load_workspace_dependencies`返回的bundled Python/Node及node_modules。所有命令在本标准目录运行；原件参数应按当前机器定位，不把本机盘符当仓库身份。

1. `python render_source.py <用户原PDF路径>`：校验SHA并渲染临时页图。文字层输出仅供诊断。
2. `python build_data.py`：从保留的手工图像录入项生成CSV/JSON。
3. 建立本目录`node_modules`junction至bundle提供的node_modules；不得改依赖目录。
4. `node build_workbook.mjs`：用Artifact Tool生成唯一XLSX、坐标和临时预览。
5. `python verify_assets.py`：用openpyxl只读XLSX，对坐标/类型/值及42原图样本核验，生成证据JSON/CSV/表定位清单。

脚本只产生本目录文件，原件只读。原页图像、提取文本、预览、依赖junction、导出inspect均由本目录`.gitignore`排除。哈希清单见[evidence/SHA256SUMS.json](evidence/SHA256SUMS.json)，不含自身，避免自引用。

平台预检查、标准问题及授权边界见[主映射第9节](../../../standards/gbt36561_2018/STANDARD_MAPPING.md#9-修订与后续接入)。资料仍为Stage A交付草稿，不将此核验记录命名为Acceptance。
