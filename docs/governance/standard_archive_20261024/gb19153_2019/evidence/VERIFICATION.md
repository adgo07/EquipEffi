- 原PDF：仓库根相对`标准原文/5. GB 19153-2019 容积式空气压缩机能效限定值及能效等级.pdf`；SHA-256 `ab4ff8e101da57ba0b5a778fa2882cb5f4eb8c2c5d403829cac83d1cef1c09cc`。封面图核对编号/名称/发布日期/实施日/替代关系，18页。执行后再次哈希一致，原文件未重存。
- 工作簿：`data/GB19153_2019_标准表值.xlsx`；SHA-256 `7686bbc675e3f3189b4d21898738dd4f4303e57cf66e0df8db52bbdc89dd7dc7`。最终机器记录见[workbook_verification.json](workbook_verification.json)。
- 提取：pdfplumber识别网格和源格边界，按原格几何覆盖展开合并格；不采用“上一个非空值”无条件填充。[extract_tables.py](extract_tables.py)生成[source_cells.csv](source_cells.csv)。源行/列含表头、从1起，M列bbox为PDF左上原点point坐标。
- 逐格复核：PDFium独立文本引擎按同一源格bbox读取，逐项比较字面数字（保留一位小数），形成[numeric_crosscheck.csv](numeric_crosscheck.csv)。参见[verify_source.py](verify_source.py)。**两个引擎处理同一PDF，不能排除PDF文本层与图像共同错误，也不是两个独立审查者。**
- 最终XLSX：Artifact Tool创建/导出并render；openpyxl仅用于只读复核实际坐标，未用于写入。[verify_workbook.py](verify_workbook.py)核对A:N全部40,866个数据单元格，表7六个比例数值另检。
