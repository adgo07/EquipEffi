## 请求 1：GB/T 755 容差的判定语义（建议前缀 EQP-STD-GB30254-）

- 类型：REFERENCE / IMPLEMENTATION。
- 【标准原文事实】第4章（PDF物理页5 / 印刷页1）规定额定输出功率下实测效率不低于表1～6，容差符合 GB/T 755；第5章（PDF6 / 印刷2）规定实测效率不低于对应表3级。第2章中 GB/T 755 为不注日期引用。未在本标准给出容差数值或如何改变等级阈值的算式。
- 【技术判断】“表值”与“允许容差后的符合性界限”须区分。不能从旧版代码或常见效率允差公式直接推定新版本适用规则，更不能自行给3级下调阈值。
- 【建议软件处理，未批准】保存表格原值；没有取得适用GB/T 755条款、额定/保证效率与实测效率关系证据之前，不新增容差扣减算法。主映射可说明名义阈值比较，但完整含容差结论仍需确认。
- 影响：所有表、极数、等级在阈值下方的边界；未来 threshold_compare / tolerance_policy。未改生产代码、Golden或既有解释。
- 候选：表1/200kW/2极，93.1%恰等于2级；93.09%低于2级但高于3级，容差是否允许仍声称2级需确认；92.29%略低于3级不得先行断言容差合格。
- 引用补证：官方元数据已确认现行GB/T 755—2025，2026-02-01实施，全部代替2019版；官方全文入口因国际采标版权不提供文本阅读。直接来源见[反馈回应§3](evidence/ACCEPTANCE_RESPONSE_20261013.md#3-定向补充的外部引用证据)，元数据核对不等于获得容差条款。
