## 可重现读取

渲染使用本机可用Poppler：`pdftoppm -r 130 -png <原PDF> docs/standards/gb29541_2013/tmp/page`。5张整页PNG只留本目录tmp供本地复核，不作为待上传原文副本。

工作簿由Artifact Tool创建；复核脚本`evidence/verify.py`使用pypdf从表1区独立提取45个两位小数，与同一作者原页视觉复核列表及保存后的XLSX真实F6:J14逐格比对。脚本未读取生产JSON、旧代码或旧工作簿。`evidence/build.mjs`是资料作者脚本，不是软件计算内核。
