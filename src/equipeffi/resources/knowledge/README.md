# 知识库（Knowledge）

本目录保存 EquipEffi 可长期复用的设备能效专业知识，只服务“解释”，不是业务真值源。

条目按设备类型与字段 ID 组织，未来可服务桌面表单、网页表单和 API 的字段帮助与结果解释；当前不实现知识中心 UI。

## 1. 定位

- 本目录保存**可长期复用**的专业知识：专业概念解释、参数和数据如何取得、计算与判定解释、标准理解与争议、工程实际操作建议、常见问题与典型错误、软件字段如何理解、现场资料通常在哪里取得。
- 本目录**不是** Calculator 的权威数据源或规则源，**不得**在运行时解析本目录 Markdown 来决定业务结果。业务真值链路始终是：

```text
标准 / Canonical → Rule → Calculator → Result
```

## 2. 状态与沉淀方式

- 新知识条目默认状态 `DRAFT`，不得自动成为 `PUBLISHED`；只有经过专业审核才能推进到 `REVIEWED` / `PUBLISHED`。
- 知识沉淀是**顺手沉淀**：不要求每个任务都产生知识；没有可沉淀内容时允许记录“Knowledge capture：无”，也不得为了数量制造条目或明显扩大主任务。
- 当前不建立复杂 Schema、知识数据库、向量库、RAG / AI Chat 或知识中心 UI。

## 3. 事实层级（必须区分）

每条知识必须分清并标注：

1. 标准原文事实；
2. 官方资料；
3. 专业技术解释；
4. 工程实践建议。

不得把技术判断写成标准明文，不得把工程经验写成强制标准要求；没有发布机构正式解释时，不得因为软件已采用某种处理方式就写成“官方确认”。

## 4. 最小字段

标题；状态；类型；适用标准；来源；正文；关联 Standard Issue（如有）。具体目录结构由本仓自行决定，不要求与中央仓或其他业务仓一致。

## 5. 治理规则出处

具体治理规则以中央 `Qingzhou-contracts/docs/governance/STANDARD_DEVELOPMENT_GUIDE_V0.1.md`（`ACTIVE / EVOLVING`）的“知识沉淀”部分为准；本文件不复制其正文。
