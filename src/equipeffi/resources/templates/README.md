# 内置模板

设备能效分析空白模板_重构版V6_20261005.xlsx 是运行时随包发布的正式全设备模板资源。
正式 Qt 产品从资源目录读取并提供模板下载。原V6基线的批量评价接通其中的“离心泵”Sheet。

该文件是 Owner 指定的 V6 模板基线。更新资源副本前，必须按现有模板清单和契约核验流程处理；不得删除、重排或改变未经本阶段授权的其他设备 Sheet。

V6.3（`设备能效分析空白模板_重构版V6_3.xlsx`）是电机铭牌额定输入的候选模板，
由登记的V6.2资产通过 `tools/build_v63_motor_template.py` 定点派生。V6.2仍作为
旧单位/效率口径数据的导入模板保留；V6.3中的电机额定电压单位为V，额定效率来自铭牌，
原I列隐藏、锁定并停用。离心泵、变压器、共享配置及其他未授权Sheet的原始XML字节保留。


V6.4（`设备能效分析空白模板_重构版V6_4.xlsx`）为2026-11-10授权的未发布产品接入候选，
在同一个电动机Sheet使用`motor-input.v4`：F明确GB18613低压类别或GB30254高压类别，
I仅高压填冷却IC代码，电压V、额定效率1～100百分数点值。高压状态IMPLEMENTED，待独立验收。
旧V6.3资产及其motor-input.v3保持不变，不接高压。派生命令：`python tools/build_v64_motor_template.py`。

V6.5（`设备能效分析空白模板_重构版V6_5.xlsx`）使用 `motor-input.v5`，由登记V6.4定点派生。
统一工作簿接通离心泵、变压器和电动机三个Sheet，覆盖GB19762、GB20052、GB18613、GB30254及GB30253。
电动机F列新增永磁同步电动机的低压异步起动、高压异步起动、低压变频调速、高压变频调速和电梯用五个明确分支。
I列只供GB30254高压类别及永磁高压B/D填写冷却IC代码，永磁低压A/C及电梯E留空，非空值会形成行级输入错误。
L列在永磁变频C/D和电梯E中填写额定转速，在GB18613相关类别中沿用铭牌标称最高转速。
旧V6至V6.4按各自契约读取，旧模板不接新增永磁类别。派生命令为 `python tools/build_v65_motor_template.py`。


V6.6（`设备能效分析空白模板_重构版V6_6.xlsx`）是2026-11-12授权的未发布空压机候选模板，
由V6.5只读ZIP派生，保持18个Sheet顺序，新增接通“空压机”（`compressor-input.v1`）。
A:R十八列中，F明确六个正式类别、其他类别或不确定类别；G按类别填额定功率kW：
表1/2为主驱动电动机额定输出功率合计，表3/4为额定输出功率，直联便携表5/6为机组额定输入功率。
H流量可选，I额定排气表压MPa，J表1—4填风冷/液冷而便携类别留空，K有效比功率kW/(m³/min)，
变转速类别填有效综合比功率。D数量必填正整数；L:O及R由同一Application软件内核写出，空白模板不保留第二套业务公式。
正常结果O直接显示等级，R不附加范围解释；非法输入和无法判定仍给出必要原因。
旧V6—V6.5空压机功率语义未版本化，不接通空压机评价；其原有设备输入仍按各自契约读取。
输出另存新的Workbook，一次批次只保存一条batch_record，逐行证据与结果工作簿关联；不覆盖输入。
派生命令：`python -m tools.build_v66_compressor_template`。


V6.6容量策略以输入列全列解锁、整段数据验证及Reader全行识别为准，不依赖受保护Sheet上自动扩展Excel Table。
B:K及P:Q为输入区，表头和L:O、R结果区锁定；Q1便利数量合计覆盖D4:D1048576。
序号A是便利显示，行是否有输入不以A列为准。2026-11-12修复初稿仅10行可填写的保护缺陷；
机械检查及软件批量容量证据与实际Excel/WPS操作证据分别记录，未运行GUI不作为GUI通过。
